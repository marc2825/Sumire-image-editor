Sumīre 1.6.0 / Windows 11 x64

开始使用
解压完整的 ZIP，双击 sumire.exe。无需 Python。
sumire.exe 需要同一文件夹中的 _internal。请整体保留文件夹，不要单独移动 exe。
首次启动时，从“覆盖保存原图”或“保存到其他文件夹并保留原图”中选择保存方式。如果不选择就关闭，将不更改原图，保存到其他文件夹。之后可通过右上角的“覆盖 · 自动保存 ▾”更改。
图像和文件夹也可以拖放到窗口中打开。下次会从上次的标签页和工作位置继续。
如需切换语言，请使用初始界面右下角的选择框，或打开右上角的齿轮 →“显示、导入”→“显示语言”（下次启动时生效）。

基本操作
涂抹要隐藏的部分后会自动保存。按 Enter 保存并前往下一张，用 ← → 切换前后的图像。
左侧为图像列表，中央为图像及其下方的分拣（采用、待定、不采用，按键 1、2、3），右侧为工具。可用 Ctrl+B、Ctrl+Shift+B 折叠列表和工具。
遇到问题时，请用右上角的“？”或 F1 打开帮助（可离线阅读）。

主要功能
• 工作标签页：Ctrl+T 新建，Ctrl+W 关闭。双击标签页可更改名称。
• 文件夹：可从列表上方的栏位打开或新建内部文件夹。将图像拖到文件夹上即可移动。
• 图像右键菜单：另存为、转换格式、压缩体积、超分辨率放大、比较、创建拼贴、编号、标记、从列表中移除、删除图像（移到回收站）。
• 比较、蒙版位于图像下方，裁剪、旋转、翻转和色调位于右侧面板的“调整图像”中。
• 文本：在右侧面板选择“文本”（T）后点击图像，即可添加文字。添加后也可用框移动、旋转、缩放，双击重写。
• ZIP：通过“文件 → 打开 ZIP…”或拖放，无需解压即可查看和分拣 ZIP 中的图像（只读；用“从 ZIP 导出…”取出所选图像）。
• 自定义标记：“需修正”等常用标记，可用图像下方标签右侧的按钮（4–9 键）添加或移除。
• Ctrl+C 复制编辑结果，Ctrl+V 在新标签页中打开剪贴板图像。在列表中时，则为剪切、复制、粘贴图像文件（Ctrl+X、Ctrl+C、Ctrl+V）。

元数据
默认情况下，保存时会保留元数据。删除时，请使用图像上方的“删除元数据”或列表下方的“导出和批量处理 → 批量删除所有图像的元数据…”。也可以设置为每次保存时删除。
点击图像上方的“元数据：有”即可查看包含的信息。
删除前的信息可通过“⋯ → 其他 → 另存带有恢复元数据的副本”恢复。这些信息没有加密，提示词和位置信息仍可读取。它们保存在应用专用位置，不放在图像文件夹中（从 0.4.0 或更早版本开始使用时，位于图像文件夹内的 .sumire-index.sqlite3）。
“元数据：无”是对所支持类型的检查结果。以未知方式嵌入的信息无法检查。

从右键菜单启动
确定解压后文件夹的存放位置后，选择右上角的齿轮 →“Windows 联动”→“在右键菜单中添加‘用 Sumīre 打开’”。之后右键单击图像或文件夹 →“显示更多选项”→“用 Sumīre 打开”即可启动。
移动文件夹后请重新注册，删除前请先解除注册。

更新
将新的 ZIP 解压到其他文件夹，退出旧应用后再启动。设置、记录和编辑项目可以继续使用。删除解压后的文件夹后，图像、设置和记录仍会保留。记录保存位置的更改或删除请在设置的“管理记录”中进行。如果注册了右键菜单，请从新文件夹重新注册。

卸载
1. 如果注册了右键菜单，双击解压文件夹中的 unregister-context-menu.cmd 解除注册（也可通过齿轮 →“Windows 联动”→“解除右键菜单注册”）。
2. 如需同时删除设置和记录，请先在设置的“管理记录”中删除记录，再删除 %LOCALAPPDATA%\Sumīre 文件夹（如果从 0.4.0 或更早版本开始使用，还包括图像文件夹中的 .sumire-index.sqlite3）。
3. 删除解压后的文件夹。图像不会被删除。
