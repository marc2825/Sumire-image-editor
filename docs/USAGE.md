# 操作ガイド

各機能の詳しい説明です。まず使ってみる場合は、アプリのヘルプ（F1）か[はじめての操作](../sumire/help_docs/USER_GUIDE.md)をご覧ください。キー操作は[ショートカット](../sumire/help_docs/SHORTCUTS.md)にまとめています。

## 画面

| 場所 | 内容 |
| --- | --- |
| いちばん上 | 左に「Sumīre」と「ファイル」、続いて作業タブ。右に保存方法（「上書き · 自動保存 ▾」）、ヘルプ、歯車（設定） |
| 左 | 一覧の操作（ラベルごとの書き出し・一括削除・仕分けのリセット・整理を戻す・「⋯」）、フォルダーの欄（上へ・再読み込み ⟳・新しいフォルダー）、検索（名前とメモ）、画像の一覧 |
| 中央 | 画像。画像の上に、元に戻す／やり直す・保存の状態・メタデータの有無・「メタデータを削除」・「上書きして次へ →」。画像の下に、切り抜き・比較・マスク。名前の右に「共有」（NovelAIでi2i・画像をコピー・ドラッグして渡す）と「⋯」（上書き保存・別名で保存・メタデータの削除と確認・超解像・上書き前の元画像に戻す・その他） |
| 右 | 加工のツール、「詳細設定・その他」（プリセット・範囲の拡張・回転・反転・色調）、仕分け |
| 下部 | 状態の表示、表示倍率（数値を入力して変更できます）、全体、原寸 |

画像の上の保存の状態は「未編集」「未保存」「保存中」「保存済み」「保存失敗」のいずれかです。その右の「メタデータ：有り／無し」を押すと、メタデータの内容を表示します。一覧の各画像には、編集と保存の状態、ラベル、メモの有無を表示します。
2枚以上を選ぶと、一覧の上に「N枚を選択中」の欄が出て、まとめて操作できます。

## 開く

- **フォルダー**：直下の画像を、名前の自然な順（1、2、10）に並べます。中のフォルダーは、一覧の上の欄から開きます。
- **画像**：選んだ画像だけを並べます。同じフォルダーのほかの画像は加えません。
- 作業中に開くと、今のタブに加えるか、新しいタブで開くかを選べます。今のタブに加えても、表示中の画像や編集中の内容はそのままです。
- 「フォルダーの追加画像を取り込む」（一覧の「⋯」、初期設定でオン）では、開いたフォルダーに新しく置かれた画像を、書き込みが終わってから一覧に加えます。
- 起動画面の「最近使ったフォルダー」は、右の✕で一覧から消せます（フォルダーや画像は消えません）。

### フォルダーの中を移動する

フォルダーを1つ開いたタブでは、一覧の上にフォルダーの欄が出ます。タブは開いたフォルダーを起点とし、中を移動してもタブの名前は変わりません。

- フォルダー名をクリックすると、その画像に切り替わります。「..（上のフォルダー）」か左の矢印で戻ります。起点より上には行けません。
- 今いる場所は「作品 / 差分」のように表示します。並び順・絞り込み・表示中の画像はフォルダーごとに覚え、タブを復元すると今いたフォルダーに戻ります。
- 「ファイル」から別のフォルダーを開くと、そこが新しい起点になります。
- 欄の右のボタンで、今いるフォルダーに新しいフォルダーを作ります。

### 画像をフォルダーへ移す

一覧から欄のフォルダーへドラッグするか、右クリックの「フォルダーへ移動」で移動先を選びます。複数の画像をまとめて移せます。

- 画像のデータはそのまま移します。移動先に同じ名前の画像があるときは `_2` などを付け、上書きしません。別のドライブへは、コピーして内容を確かめてから元を消します。
- ラベル・メモ・加工マスク・復元用のメタデータも一緒に移ります。別フォルダー保存の保存記録は移さないため、移した画像は移動先で未保存として扱います。
- 表示中の画像に未保存の加工があるときは、保存するかを尋ねてから移します。ほかの画像に未保存の加工があるときは移しません。
- 「直前の整理操作を戻す」（Ctrl+Alt+Z）で、元の場所と名前に戻せます。

## 作業タブ

画像やフォルダーはタブごとに開き、一覧・加工・保存方法はタブごとに独立しています。

- Ctrl+Tで新しいタブ、Ctrl+Wで閉じる、Ctrl+Tab／Ctrl+Shift+Tabで切り替え。
- タブ名はダブルクリックか右クリックで変えられます（60文字まで。空欄でフォルダー名に戻ります）。同じフォルダーを開き直したときにも、その名前を使います。
- 未保存の加工があるタブを閉じるときは、保存するかを尋ねます。保存に失敗したときは閉じません。
- 終了時のタブ・並び順・絞り込み・表示中の画像・設定を覚え、次の起動で復元します。画像を読み込むのは表示したタブだけです。起動時に画像やフォルダーを指定した場合は、それだけを開きます。

## 保存

保存方法は初回の起動時に選び、あとから右上の「上書き · 自動保存 ▾」で変えられます。0.4.0以前から使っている場合や、初回の画面を閉じた場合は、上書き・自動保存になっています。

- **元画像に上書き**：PNG・JPEG・WebPを、同じ場所・名前・形式で置き換えます。ほかの形式は上書きできないため、別フォルダーに保存してください。起動して最初に上書きするときは、確認を表示します（「今後この確認を表示しない」で消せます）。
- **別フォルダーに保存**：元画像のフォルダー内の `Sumīre` に保存し、元画像は変えません。保存先と形式（PNG・JPEG・可逆WebP）は変更できます。
- **上書き前の元画像を一時的に残す**（初期状態でオン）：起動して最初に上書きする前の元画像を、OSの一時フォルダーに残します。「⋯ → 上書き前の元画像に戻す」で、メタデータも含めて元のファイルに戻せます。残した元画像は、アプリを終了すると削除します（強制終了で残った分は、7日を過ぎると次の起動時に削除します）。
- **保存するときにメタデータを削除**（初期状態でオフ）：オフのときは、元画像のメタデータを残して保存します（形式を変えて保存する場合を除く）。オンにすると、保存のたびに削除して確かめます。「メタデータを削除」と一括削除は、この設定にかかわらず削除します。
- 自動保存がオンなら、なぞるたびに保存します。オフなら、ほかの画像へ移るときに保存するかを尋ねます。
- 加工していない画像は、移るだけでは保存しません。Enter（保存して次へ）では、加工していなくても保存します。
- 保存に失敗しても加工は残ります。保存中にさらに加工した場合は、先の保存が終わってから最新の状態を保存します。
- Ctrl+Zで元画像の状態まで戻すと、一覧の表示も「未編集」に戻ります。

保存の仕組みや確認していることは、[保存とプライバシー](SAVING_AND_PRIVACY.md)にあります。

## 加工

| ツール | 内容 |
| --- | --- |
| モザイク | 強さはブロックの大きさです。`,` と `.` で2pxずつ変えられます |
| ぼかし | 強さはぼかしの半径です |
| 塗りつぶし | 色と不透明度（0〜100%）を選べます。100%で元の画素を完全に置き換えます |
| 消しゴム | なぞった部分を元画像に戻します。もう一度押すと（E）元のツールに戻ります |

- **範囲の形**：ブラシ・長方形・楕円・多角形・投げ縄。選ぶ欄にマウスを重ねると、それぞれの使い方が出ます。
  - 多角形：クリックで頂点を足し、Enterかダブルクリックで確定、Backspaceで頂点を戻し、Escで中止します。
  - 投げ縄：ドラッグして囲みます。始点と終点は結ばず、線が交わってできた最初の閉じた範囲を一瞬示してから、そこに適用します。線が交わらなければ何もしません。
- **外側に適用**：「⋯ → その他 → 選択範囲を反転」をオンにすると、次に囲む範囲の外側を加工します（ブラシを除く）。
- **範囲の拡張**：なぞった・囲んだ範囲を、外側へ0〜3px広げて加工します（初期値1px。「詳細設定・その他」）。輪郭のきわが加工されずに残るのを防ぎます。
- **数値の入力**：ブラシの直径・強さ（不透明度）・範囲の拡張は、スライダーのほか、名前の右の欄に数値を入力して変えられます（Enterで反映）。
- **スポイトと直線**：Alt＋クリックで色を拾い、Shift＋クリックで直前のブラシ位置から直線を引きます。
- **比較とマスク**：画像の下の「比較」かTabを押している間、元画像を表示します。「マスク」（M）は加工した範囲を青く重ねて表示します。この色は保存されません。
- **加工・マスクを初期化**：確認のうえ、すべての加工を消して元画像に戻します。Ctrl+Zで取り消せます。開く前から画像に入っていた加工は戻せません。
- **編集プリセット**：ツール・ブラシの大きさ・強さ・色・形・範囲の拡張に名前を付けて保存し、呼び出せます（「詳細設定・その他」）。

加工した範囲（マスク）は保存時に管理記録へ残し、画像を開き直すと復元します。ほかのアプリで画像が変更された場合は使いません。マスクを白黒のPNGで書き出すこともできます（「⋯ → その他 → 加工マスクをPNGで保存」）。

## 切り抜き・回転・色調・超解像

- **切り抜き**：画像の下の「切り抜き」。最初は画像全体が枠で囲まれ、四隅や辺をドラッグして範囲を狭めます。枠の内側をドラッグすると移動します。数値（左端・上端・幅・高さ）でも指定できます。「出力の寸法を指定する（拡大・縮小）」をオンにすると、切り抜いた範囲を指定の幅×高さにします。「幅と高さの比率を保つ」では、片方を変えるともう片方も同じ割合で変わります。
- **回転・反転**：「詳細設定・その他」のボタンで、すぐに適用します。
- **色調**：「詳細設定・その他」の「色調の調整」。明るさ・コントラスト・彩度・色相・露出・色温度・ガンマのほか、「詳細調整」でハイライト・シャドウ・白レベル・黒レベル・RGBバランス・シャープネスを変えられます。画面内の「元に戻す」「やり直す」で一手ずつ戻せ、スライダーのダブルクリックで初期値に戻ります。透明度と加工の範囲は保ちます。
- **超解像**：「⋯ → その他」か画像の右クリックの「その他 → 超解像を適用」。表示中の画像を1.5〜4倍に拡大します。拡大後が1辺32,768px・2,400万画素を超える倍率は選べません。**隠した部分が復元されることはありません。**

どれも画像とマスクを一緒に変え、「元に戻す」で寸法ごと戻せます。上書き保存の設定では、切り抜き・超解像の前に確認します。上書きして終了すると、切り落とした部分は元に戻せません。

## 仕分け

右下の「採用」「保留」「不採用」（1・2・3）でラベルを付けます。もう一度押すと外れます。Alt+0でも外せます。複数を選んでいれば、まとめて付きます。

- ラベルはすぐに保存され、再起動・保存・名前の変更・フォルダーの移動の後も残ります。画像の内容は変えません。
- 絞り込みボタンで、ラベルごとに表示を絞れます。件数は一覧の下に出ます。
- 「ラベルを付けたら次へ」をオンにすると、付けるたびに次の画像へ進みます。
- 「仕分けをリセット」で、タブ内のラベルをまとめて外します。
- 一覧の「⋯ → 一覧を初期状態に戻す」で、この起動中に元画像を残して上書きした画像を元のファイルに戻し、表示中の画像の加工とマスクを消し、ラベル・メモ・並び順・絞り込み・検索も解除します。この起動より前に保存した加工と、元画像を残していない上書きは戻せません。
- 「ラベルごとに書き出す」で、採用・保留・不採用のどれか、またはすべてのラベルの画像を、ラベル名のフォルダーへ分けます。既定では、開いているフォルダーにラベル名のフォルダーを作り、一覧の順に00, 01…と名前を振り直して**元画像を移動**します（ラベル・メモも一緒に移り、「直前の整理操作を戻す」で戻せます。保存していない加工がある画像は、先に保存してください）。
- 「元画像を移動する」をオフにすると、元画像はそのままで、編集後の画像を新しいファイルとして書き出します。保存していない加工も反映し、メタデータは含めません。形式も選べます。
- 保存先と連番の有無は変えられます。

## 整理

- **検索**：検索欄（Ctrl+F）にファイル名の一部を入れます。
- **並び順**：名前順と更新日時順（昇順・降順）から選びます。一覧の画像をドラッグすると、手動の順番になります。
- **名前の変更**：画像名のダブルクリックかF2。拡張子は変わりません。
- **連番**：一覧の「⋯ → 順に連番へ改名」（全体）か右クリック（選んだ画像）。一覧の順に0から番号を振り、桁は最大の番号より1桁多くそろえます（3枚なら00〜02、11枚なら000〜010）。変更前後の名前を確かめてから実行します。
- **メモ**：右クリックの「メモ」。4000文字まで書け、一覧にマウスを重ねると読めます。
- **一覧から外す**：右クリック。ファイルは消えません。Ctrl+Rで戻ります。
- **重複を削除**：一覧の「⋯ → 重複を削除」。内容が同じ画像の組ごとに残す1枚を選び、残りをごみ箱へ移します。
- **比較**：2〜6枚を選んで右クリックの「複数枚を並べて比較」。拡大は画像ごとで、「拡大・移動を連動」でそろえられます。
- **直前の整理操作を戻す**：一覧の上の矢印（Ctrl+Alt+Z）。ラベル・並び順・名前・メモ・フォルダーの移動を、新しい順に戻します。名前を変えた後に画像が変わっていた場合は戻しません。

名前の変更では画像を書き直しません。変更先に同じ名前のファイルがあれば中止します。途中で止まった場合も、次に開いたときに元へ戻すか確定できます。

## 書き出し

| 操作 | 場所 | 内容 |
| --- | --- | --- |
| 別名で保存 | 「⋯」・右クリック | 名前と形式を選んで新しいファイルに保存 |
| 形式を変換 | 右クリック・一覧の「⋯」 | PNG・JPEG・WebP・AVIF・BMP・TIFF・GIFへ変換 |
| 容量削減 | 右クリック・一覧の「⋯」 | 画質を保つ方法か、画質が落ちる可能性のある方法でファイルを小さくする |
| コラージュ | 2枚以上を選んで右クリック | 2〜16枚を格子（左右・上下・2×2など）に並べるか、自由に配置して1枚にする |

- 元画像は変えません。変換と容量削減では、開いているフォルダーに「変換済み」「圧縮済み」を作って書き出します（保存先は変えられます）。同じ名前のファイルは上書きしません。
- 容量削減では、方法を選ぶたびに1枚目を実際に変換して「元画像3.2 MB → 圧縮後740 KB（77%削減）」のように示します。実行時は全画像を変換して合計を確かめてから書き出し、取り消せば何も残しません。長辺の縮小も選べます。
- 画質を保つ方法：PNGの最適化（256色以下なら色数をそのまま減らす）、WebPの可逆圧縮。画質が落ちる可能性のある方法：JPEG・WebP・AVIF、PNGの減色。
- JPEGとBMPは透過部分を白にし、GIFは256色になります。HEICには対応していません。
- コラージュでは、画像をダブルクリックすると、その場に切り抜きの枠が出ます。切り落とす部分は薄く表示され、枠の外をクリックすると確定します。「自由に配置」では、画像をドラッグして動かし、角をドラッグして拡大・縮小し、キャンバスの大きさを決められます。クリックした画像が前面に来ます。切り抜きはコラージュにだけ使い、元の画像は変わりません。
- 書き出したファイルは読み直して、形式・寸法・メタデータがないことを確かめます。画質を保つ方法では、画素が変わっていないことも確かめます。
- 「削除前のメタデータを復元用に保存」がオンなら、元画像のメタデータを書き出したファイルとひも付けて残します。

## コピー・貼り付け

Ctrl+Cで編集結果をコピーし、Ctrl+V（または「ファイル → クリップボードの画像を開く」）でクリップボードの画像を新しいタブに開きます。どちらもメタデータを含みません。文字の入力中は、文字のコピーと貼り付けが優先されます。
貼り付けた画像は手動保存で始まり、最初の保存で保存先を選びます。タブを復元するため、設定と同じ場所の `clipboard-images` に画像を保管します。不要になったら、アプリを終了してから削除できます。

## 編集プロジェクト

「ファイル → 元画像を含む編集プロジェクトを保存」で、元画像・加工後の画像・マスクを `.sumire` ファイルにまとめます。元画像がなくても、開き直して消しゴムで加工を戻せます。
**隠した部分の加工前の内容も入っています。** 共有には、通常の保存で作った画像を使ってください。編集の履歴は含みません。

## 共有（NovelAIへ渡す・ほかのアプリへ渡す）

画像名の右の「共有」から選びます。どれも、加工した画像（保存前の加工も含む）をメタデータなしで渡します。

- **画像をコピー**：投稿欄やチャットに貼り付けられます。
- **ドラッグして渡す**：渡す画像を小さな画面に出します。ブラウザーの投稿欄やチャットアプリへドラッグしてください。
- **NovelAIでi2i**：次の手順です。

1. 「共有 → NovelAIでi2i」を選ぶと、画像をクリップボードにコピーし、ブラウザーでNovelAIを開きます。
2. NovelAIにログインし、貼り付けるか、Sumīreの画面から画像をドラッグします。
3. 「Image2Image」を選びます。

元のファイル名やプロンプトは渡しません。「歯車 → NovelAI連携」をオンにすると、渡す前に切り抜きと縮小ができます。手順は[NovelAIの説明](https://docs.novelai.net/ja/image/image2image/)に沿っています。

## 設定

右上の歯車で開き、左の項目を選んで変更します。左下の「設定を初期状態に戻す」で、すべての設定（ショートカットキーと編集プリセットを含む）を最初の状態に戻せます。管理記録、Windowsの右クリックへの登録、最近使ったフォルダー、表示言語はそのままです。

| 項目 | 内容 |
| --- | --- |
| 保存 | 自動保存、上書き、復元用のメタデータ、別フォルダー保存の形式と保存先、JPEGの品質（1〜100、初期値95） |
| 管理記録 | 記録の保存先の切り替えと削除 |
| ショートカット | キー操作の変更 |
| 表示・取り込み | 表示言語（日本語・英語・簡体字中国語。次の起動から）、ナビゲーター、フォルダーの追加画像の取り込み、ラベルを付けたら次へ、終了するときの確認、全画面表示 |
| NovelAI連携 | 渡す前の切り抜き・縮小 |
| Windows連携 | 右クリックへの登録と解除 |
| 情報 | バージョン、ライセンス、前回のエラー詳細 |

ウィンドウを閉じるときは、終了してよいかを確認します。終了すると、元に戻す・やり直すの履歴と、上書き前に残した元画像は消えます。保存していない加工は、終了の前に保存します（自動保存がオフのタブでは、画像ごとに確認します）。確認は「今後この確認を表示しない」か、設定の「表示・取り込み」で止められます。

設定は `sumire-workspace.json` に保存します（場所は環境変数 `SUMIRE_SETTINGS_FILE` でも指定できます）。再開用のフォルダーのパスを含みますが、画像は含みません。削除すると初期設定に戻ります。

## Windowsの右クリックから開く

「歯車 → Windows連携 → 右クリックに『Sumīreで開く』を追加」で、画像（PNG・JPEG・WebP・BMP）・フォルダー・フォルダーの余白の右クリックに「Sumīreで開く」が加わります。Windows 11では「その他のオプションを確認」の中に表示されます。

- 登録は今のWindowsユーザーだけに行い、既定のアプリは変えません。「右クリックの登録を解除」で取り除けます。
- exeを移動したら登録し直し、削除する前に解除してください。
- Sumīreが起動中なら、その画面で開きます。処理中なら、終わってから開きます。
