# Stealth PNGInfo

NovelAIなどが、生成情報（プロンプトや設定）を**画素の値そのもの**に埋め込む方式です。PNGのテキストやEXIFとは別の場所にあるため、一般的なメタデータの削除ツールでは消えず、ExifToolなどでも見つかりません。Sumīreは、この方式を見つけて消します。

## 形式

画素の色や透明度は、それぞれ0〜255の値です。この値の一番下のビット（最下位ビット）を1ビットずつの記録に使います。値が最大1変わるだけなので、見た目では分かりません。

| 署名 | 埋め込む場所 | 本体 |
| --- | --- | --- |
| `stealth_pngcomp` | 透明度（アルファ）の最下位ビット | gzipで圧縮した生成情報（NovelAIが使う方式） |
| `stealth_pnginfo` | 透明度の最下位ビット | 圧縮していない生成情報 |
| `stealth_rgbcomp` | 赤・緑・青の最下位ビット | gzipで圧縮した生成情報 |
| `stealth_rgbinfo` | 赤・緑・青の最下位ビット | 圧縮していない生成情報 |

- **読む順番**：左上の画素から下へ1列ずつ読み、列の下端まで来たら右隣の列へ進みます（列優先）。赤・緑・青を使う方式では、1画素から3ビット読みます。8ビットずつ、上位のビットから順にまとめて1バイトにします。
- **並び**：先頭の15バイトが署名、次の4バイトが本体の長さ（ビット数、ビッグエンディアン）、その後が本体です。
- NovelAIの不透明な画像では、透明度が255と254の2つの値をとり、その違いで1ビットを表します。

## 見つけ方

画像を開いたときに、先頭の120ビット（15バイト）だけを読み、表の4つの署名のどれかと一致するかを調べます。一致しなければ普通の画像として扱います。削除のために本体を読み出したり、展開したりはしません。

「メタデータの内容を確認」では、表示のために本体を読み出します。圧縮されたものは展開し、展開後に4MiBを超えるものや読み取れないものは「不明」とします。

## 消し方

署名が見つかったら、本体の長さにかかわらず、そのチャンネルの最下位ビットを**画像全体で**そろえます。

- 透明度の方式：254と255を255に（不透明に戻す）、それ以外の値は偶数にします。NovelAIの不透明な画像は、色も寸法も変わりません。
- 赤・緑・青の方式：各色の値を偶数にします。色は最大1段階変わります。

消すのは、画像を開いた直後、向きの補正や色の変換より前です。回転すると読む順番が変わって署名が見つからなくなり、色を変換すると最下位ビットが崩れて一部だけが残るためです。メタデータを削除する保存では、保存した画像を読み直して、署名が残っていないことも確かめます。

## メタデータを残す設定のとき

元のファイルから本体を読み出して、加工後の画素に同じ方式で埋め込み直します。メタデータを残す保存は元と同じ形式で保存するときに限るので、NovelAIのPNGをPNGのまま保存したときに埋め込み直すことになります。JPEGは圧縮で最下位ビットが崩れるため、埋め込めません。

## 限界

- 見つけられるのは、表の4つの署名の方式だけです。ほかの方法で画素に埋め込まれた情報は見つけられません。
- 画像生成AIが付ける「見えない電子透かし」（周波数成分に埋め込む方式など）は、検出も削除もしません。
- JPEGへの変換や拡大・縮小で崩れることはありますが、確実に消えるとは限りません。消すには、Sumīreの「メタデータを削除」を使ってください。
