# 仕組みの解説

Sumīreの中で使っている処理の仕組みと、参考にした資料をまとめています。使い方を知るだけなら読む必要はありません。操作の説明は[操作ガイド](../USAGE.md)、保存とメタデータの扱いは[保存とプライバシー](../SAVING_AND_PRIVACY.md)をご覧ください。

| 文書 | 内容 |
| --- | --- |
| [超解像（Lanczos3による拡大）](UPSCALING.md) | 「超解像を適用」と、寸法の変更・縮小に使う補間の方法。機械学習による超解像との違い |
| [モザイク・ぼかし・塗りつぶし](HIDING.md) | 隠す処理の計算方法と、それぞれに残る情報 |
| [Stealth PNGInfo](STEALTH_PNGINFO.md) | NovelAIなどが画素に埋め込む生成情報の形式と、見つけ方・消し方 |
| [重複と似た画像の判定](DUPLICATES.md) | 「重複を削除」の判定方法と、似た画像を見分けるための仕組み |

各文書では、方法・該当するコード・限界・参考資料の順に説明します。説明とコードが食い違う場合は、コードの動作が正しいものとして文書を直します。
