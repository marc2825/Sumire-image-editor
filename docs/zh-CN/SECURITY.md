# 安全与信息泄露的报告

Sumīre 是用于删除图像中所含信息的应用。对于本应删除的信息仍有残留的问题，会优先处理。

## 希望报告的内容

- 保存的图像中残留元数据或生成提示词（包括显示“元数据：无”的情况）
- 能够取出用马赛克、模糊或填充隐藏部分的原像素
- 用于恢复的记录、临时文件或设置文件中残留了意外的信息
- 未经确认就覆盖或删除了原图或现有文件
- 可以滥用右键启动等功能，打开或操作意外的文件

马赛克和模糊无法完全隐藏等已知限制，见[保存与隐私](SAVING_AND_PRIVACY.md)。

## 报告方法

**请不要写在公开的 Issue 中。** 请通过 GitHub 仓库“Security”标签页中的“Report a vulnerability”非公开报告。如果是从发布网站获取的，请使用发布页面的联系方式。

以下信息会很有帮助：

- Sumīre 的版本（齿轮 → 信息）和操作系统
- 重现步骤，以及预期结果和实际结果
- 残留信息的类型（EXIF、PNG 文本、Stealth PNGInfo 等）

**请不要附加私人图像或用于恢复的记录（`.sumire-index.sqlite3` 等）。** 请使用合成图像或可以公开的图像进行重现。

## 对象版本

修复针对最新的发行版本进行。使用旧版本时，请确认最新版本中是否也会发生。
