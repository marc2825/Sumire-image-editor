# 问题报告与需求

Sumīre 由个人开发。不一定能对所有内容回复或处理，但会按以下方式受理。

| 内容 | 渠道 | 处理 |
| --- | --- | --- |
| 信息泄露、安全 | [SECURITY.md](SECURITY.md)（非公开报告） | 最优先 |
| 保存、元数据删除、重命名、文件丢失等问题 | GitHub 的 Issue | 优先 |
| 显示或操作的问题 | GitHub 的 Issue | 依次处理 |
| 功能需求 | GitHub 的 Issue | 视内容考虑 |
| 使用方法的问题 | 请先阅读帮助（F1）和[常见问题](../../sumire/help_docs/zh_CN/FAQ.md) | 用于改进说明 |

## 报告问题时

- Sumīre 和 Windows 的版本（可在齿轮 → 信息 → 上次错误的详细信息中复制）
- 重现步骤、预期结果、实际结果
- 图像格式（PNG、JPEG、WebP 等）和大致大小
- 保存方式（覆盖 / 其他文件夹，自动 / 手动）

**请不要附加私人图像或用于恢复的记录。** 请使用合成图像或可以公开的图像进行重现。

## 不会添加的功能

不会添加账户、云同步以及使用在线服务 API 的功能。所有图像处理都在本机进行。

## 提交代码时

请先在 Issue 中商量内容。测试的运行方法和代码结构见[开发与构建](../DEVELOPMENT.md)（日语）。提交前请确认 `python -m pytest -q` 全部通过。提交的代码将以与本仓库相同的 [MIT License](../../LICENSE) 公开。
