# 操作指南

各功能的详细说明。想先试用时，请阅读应用内的帮助（F1）或[入门操作](../../sumire/help_docs/zh_CN/USER_GUIDE.md)。按键操作汇总在[快捷键](../../sumire/help_docs/zh_CN/SHORTCUTS.md)中。

## 界面

| 位置 | 内容 |
| --- | --- |
| 最上方 | 左侧为“Sumīre”和“文件”，接着是工作标签页。右侧为保存方式（“覆盖 · 自动保存 ▾”）、帮助、齿轮（设置） |
| 左侧 | 列表操作（按标签导出、批量删除、重置分拣、撤销整理、“⋯”）、文件夹栏（上一级、重新加载 ⟳、新建文件夹）、搜索（名称和备注）、图像列表 |
| 中央 | 图像。图像上方为撤销 / 重做、保存状态、是否有元数据、“删除元数据”、“覆盖并下一张 →”。图像下方为裁剪、比较、蒙版。名称右侧为“分享”（用 NovelAI 图生图、复制图像、拖动交付）和“⋯”（覆盖保存、另存为、删除和查看元数据、超分辨率放大、恢复覆盖前的原图、其他） |
| 右侧 | 加工工具、“详细设置、其他”（预设、范围扩展、旋转、翻转、色调）、分拣 |
| 底部 | 状态显示、显示倍率（可输入数值更改）、全部、原尺寸 |

图像上方的保存状态为“未编辑”“未保存”“正在保存…”“已保存”“保存失败”之一。点击旁边的“元数据：有 / 无”可显示元数据的内容。列表中的每张图像会显示编辑和保存状态、标签以及是否有备注。
选择 2 张以上时，列表上方会出现“已选择 N 张”栏，可一起操作。

## 打开

- **文件夹**：按名称的自然顺序（1、2、10）列出其中的图像。内部的文件夹从列表上方的栏位打开。
- **图像**：只列出所选的图像。不会添加同一文件夹中的其他图像。
- 工作中打开时，可以选择添加到当前标签页或在新标签页中打开。添加到当前标签页时，当前显示的图像和编辑内容保持不变。
- 开启“导入文件夹中新增的图像”（列表的“⋯”，默认开启）后，新放入当前文件夹的图像会在写入完成后加入列表。
- 初始界面的“最近使用的文件夹”可用右侧的 ✕ 从列表中移除（不会删除文件夹和图像）。

### 在文件夹内移动

在打开一个文件夹的标签页中，列表上方会显示文件夹栏。标签页以打开的文件夹为起点，在内部移动时标签页名称不变。

- 点击文件夹名称即可切换到其中的图像。用“..（上一级文件夹）”或左侧的箭头返回。不能超出起点。
- 当前位置显示为“作品 / 差分”的形式。排序、筛选和当前图像按文件夹分别记住，恢复标签页时会回到原来所在的文件夹。
- 从“文件”打开其他文件夹时，该文件夹成为新的起点。
- 用栏右侧的按钮可在当前文件夹中新建文件夹。

### 将图像移到文件夹

从列表拖到栏中的文件夹上，或在右键菜单的“移动到文件夹”中选择目标位置。可一次移动多张图像。

- 图像数据原样移动。目标位置存在同名图像时会添加 `_2` 等，不会覆盖。移到其他驱动器时，会先复制并确认内容，再删除原文件。
- 标签、备注、编辑蒙版和用于恢复的元数据也会一起移动。保存到其他文件夹时的保存记录不会移动，因此移动后的图像在目标位置视为未保存。
- 当前图像有未保存的加工时，会先询问是否保存再移动。其他图像有未保存的加工时不会移动。
- 用“撤销上一次整理操作”（Ctrl+Alt+Z）可恢复到原来的位置和名称。

## 工作标签页

图像和文件夹在各自的标签页中打开，列表、加工和保存方式在每个标签页中相互独立。

- Ctrl+T 新建标签页，Ctrl+W 关闭，Ctrl+Tab / Ctrl+Shift+Tab 切换。
- 双击或右键单击标签页可更改名称（最多 60 个字符，留空则恢复为文件夹名称）。重新打开同一文件夹时也会使用该名称。
- 关闭有未保存加工的标签页时，会询问是否保存。保存失败时不会关闭。
- 会记住退出时的标签页、排序、筛选、当前图像和设置，在下次启动时恢复。只有显示的标签页才会读取图像。启动时指定了图像或文件夹时，只打开它们。

## 保存

保存方式在首次启动时选择，之后可通过右上角的“覆盖 · 自动保存 ▾”更改。如果从 0.4.0 或更早版本开始使用，或关闭了首次设置界面，则为覆盖、自动保存。

- **覆盖保存原图**：以相同的位置、名称和格式替换 PNG、JPEG、WebP。其他格式无法覆盖，请保存到其他文件夹。每次启动后首次覆盖时会显示确认（可用“以后不再显示此确认”关闭）。
- **保存到其他文件夹**：保存到原图所在文件夹内的 `Sumīre`，不更改原图。保存位置和格式（PNG、JPEG、无损 WebP）可以更改。
- **临时保留覆盖前的原图**（默认开启）：将启动后首次覆盖前的原图保存在系统的临时文件夹中。通过“⋯ → 恢复覆盖前的原图”可连同元数据恢复原文件。保留的原图会在应用退出时删除（因强制结束而残留的部分，会在超过 7 天后的下次启动时删除）。
- **保存时删除元数据**（默认关闭）：关闭时，保存时保留原图的元数据（以其他格式保存时除外）。开启后，每次保存都会删除并确认。无论此设置如何，“删除元数据”和批量删除都会删除。
- 自动保存开启时，每次涂抹都会保存。关闭时，切换到其他图像时会询问是否保存。
- 未加工的图像仅切换不会保存。按 Enter（保存并下一张）时，即使未加工也会保存。
- 即使保存失败，加工也会保留。保存过程中继续加工时，会在前一次保存完成后保存最新状态。
- 用 Ctrl+Z 撤销到原图状态时，列表中的显示也会恢复为“未编辑”。

保存的机制和检查内容见[保存与隐私](SAVING_AND_PRIVACY.md)。

## 加工

| 工具 | 说明 |
| --- | --- |
| 马赛克 | 强度为色块大小。用 `,` 和 `.` 以 2px 为单位调整 |
| 模糊 | 强度为模糊半径 |
| 填充 | 可选择颜色和不透明度（0–100%）。100% 时完全替换原像素 |
| 橡皮擦 | 将涂抹的部分恢复为原图。再按一次（E）返回原来的工具 |

- **范围形状**：画笔、矩形、椭圆、多边形、套索。将鼠标悬停在选择栏上可查看各自的用法。
  - 多边形：单击添加顶点，按 Enter 或双击确定，Backspace 撤回顶点，Esc 取消。
  - 套索：拖动圈选。不会连接起点和终点，会先短暂显示线条交叉形成的第一个闭合区域，然后应用于该区域。线条没有交叉时不进行任何操作。
- **应用于外侧**：开启“⋯ → 其他 → 反选”后，加工下一次圈选范围的外侧（画笔除外）。
- **范围扩展**：将涂抹或圈选的范围向外扩展 0–3px 后再加工（默认 1px，位于“详细设置、其他”）。防止轮廓边缘残留未加工的部分。
- **输入数值**：画笔直径、强度（不透明度）和范围扩展，除滑块外，也可在名称右侧的栏中输入数值（按 Enter 生效）。
- **吸管与直线**：Alt+单击取色，Shift+单击从上一个画笔位置画直线。
- **比较与蒙版**：按住图像下方的“比较”或 Tab 期间显示原图。“蒙版”（M）会用蓝色叠加显示加工范围。此颜色不会保存。
- **重置加工、蒙版**：确认后清除所有加工，恢复为原图。可用 Ctrl+Z 撤销。打开前就已存在于图像中的加工无法清除。
- **编辑预设**：为工具、画笔大小、强度、颜色、形状和范围扩展命名并保存，之后可调用（“详细设置、其他”）。

加工范围（蒙版）会在保存时保存到管理记录中，重新打开图像时恢复。图像被其他应用更改时不会使用。蒙版也可以导出为黑白 PNG（“⋯ → 其他 → 将编辑蒙版保存为 PNG”）。

## 裁剪、旋转、色调、超分辨率放大

- **裁剪**：图像下方的“裁剪”。框一开始围住整个图像，拖动四角或边缘缩小范围，拖动框内可移动。也可以输入数值（左边、上边、宽、高）。开启“指定输出尺寸（放大、缩小）”后，会将裁剪范围调整为指定的宽 × 高。开启“保持宽高比例”时，更改一边另一边也会按相同比例变化。
- **旋转、翻转**：“详细设置、其他”中的按钮，点击即可应用。
- **色调**：“详细设置、其他”中的“调整色调”。除亮度、对比度、饱和度、色相、曝光、色温、伽马外，还可在“详细调整”中更改高光、阴影、白色色阶、黑色色阶、RGB 平衡和锐度。窗口内的“撤销”“重做”可逐步返回，双击滑块恢复初始值。透明度和加工范围保持不变。
- **超分辨率放大**：“⋯ → 其他”或图像右键菜单的“其他 → 超分辨率放大”。将当前图像放大 1.5–4 倍。放大后超过每边 32,768 px 或 2400 万像素的倍率无法选择。**隐藏的部分不会被恢复。**

以上操作都会同时更改图像和蒙版，可用“撤销”连同尺寸一起恢复。覆盖保存设置下，裁剪和超分辨率放大前会确认。覆盖保存并退出后，裁掉的部分无法恢复。

## 分拣

用右下角的“采用”“待定”“不采用”（1、2、3）设置标签。再按一次即可取消，也可用 Alt+0 取消。多选时会一起设置。

- 标签会立即保存，重启、保存、重命名和文件夹移动后仍会保留。不会改变图像内容。
- 用筛选按钮可按标签筛选显示。数量显示在列表下方。
- 开启“设置标签后前往下一张”后，每次设置标签都会前往下一张图像。
- 开启“自动分入标签文件夹”（右键的“标签”，或设置 → 显示、导入 → 分拣）后，在有采用、待定、不采用文件夹的位置，加上标签的图像会立即移入对应文件夹：图像所在文件夹中有标签文件夹时移入其中，图像位于标签文件夹中时移入旁边的文件夹（在“待定”中改为采用会移到“采用”）。尚不存在的标签文件夹会自动创建，取消标签时不会移动。可通过“撤销上一次整理操作”撤回。
- “重置分拣”会一次清除标签页中的所有标签。
- 列表的“⋯ → 将列表恢复为初始状态”会将本次启动中保留了原图的覆盖恢复为原文件，清除当前图像的加工和蒙版，并解除标签、备注、排序、筛选和搜索。本次启动前保存的加工，以及未保留原图的覆盖无法恢复。
- “按标签导出”会将采用、待定、不采用之一或所有标签的图像分到以标签命名的文件夹中。默认会在当前文件夹中创建这些文件夹，按列表顺序重新命名为 00, 01…，并**移动原图文件**（标签和备注会一起移动，可通过“撤销上一次整理操作”撤回；有未保存加工的图像请先保存）。
- 关闭“移动原图文件”时，原图不变，将编辑后的图像导出为新文件：包含未保存的加工，不包含元数据，也可选择格式。
- 保存位置和是否编号可以更改。

## 整理

- **搜索**：在搜索框（Ctrl+F）中输入文件名的一部分。
- **排序**：可选择按名称或按修改时间（升序、降序）。拖动列表中的图像会变为手动顺序。
- **重命名**：双击图像名称或按 F2。扩展名不会改变。
- **编号**：列表的“⋯ → 按顺序重新编号”（全部）或右键菜单（所选图像）。按列表顺序从 0 开始编号，位数比最大编号多一位（3 张为 00–02，11 张为 000–010）。执行前会确认更改前后的名称。
- **备注**：右键菜单的“备注”。最多 4000 个字符，将鼠标悬停在列表中的图像上即可阅读。
- **从列表中移除**：右键菜单。不会删除文件，Ctrl+R 可恢复。
- **删除图像**：右键菜单的“删除图像…”。确认后移到回收站（不会彻底删除）。
- **删除重复**：列表的“⋯ → 删除重复”。为每组内容相同的图像选择要保留的一张，其余移到回收站。
- **比较**：选择 2–6 张，右键菜单的“并排比较多张”。缩放按图像分别进行，开启“联动缩放与移动”可保持一致。
- **撤销上一次整理操作**：列表上方的箭头（Ctrl+Alt+Z）。从新到旧撤销标签、排序、名称、备注和文件夹移动。重命名后图像被更改时不会撤销。

重命名不会重写图像。目标位置存在同名文件时会中止。即使中途停止，下次打开时也可以恢复原名称或确定更改。

## 导出

| 操作 | 位置 | 内容 |
| --- | --- | --- |
| 另存为 | “⋯”、右键菜单 | 选择名称和格式，保存为新文件 |
| 转换格式 | 右键菜单、列表的“⋯” | 转换为 PNG、JPEG、WebP、AVIF、BMP、TIFF、GIF |
| 压缩体积 | 右键菜单、列表的“⋯” | 以保持画质或可能降低画质的方式减小文件 |
| 创建拼贴 | 选择 2 张以上后右键单击 | 将 2–16 张图像按网格（左右、上下、2×2 等）或自由排列合成为 1 张 |

- 不会更改原图。转换格式和压缩体积会在当前文件夹中创建“已转换”“已压缩”文件夹并导出（保存位置可以更改）。不会覆盖同名文件。
- 压缩体积时，每次选择方式都会实际转换第 1 张并显示结果，例如“原图 3.2 MB → 压缩后 740 KB（减少 77%）”。执行时会转换所有图像并确认总量后再导出，取消则不留下任何文件。也可以选择缩小长边。
- 保持画质的方式：PNG 优化（256 色以下时以原色数转换为调色板）、WebP 无损压缩。可能降低画质的方式：JPEG、WebP、AVIF、PNG 减色。
- JPEG 和 BMP 会将透明部分变为白色，GIF 为 256 色。不支持 HEIC。
- 在拼贴中，双击图像会就地显示裁剪框。裁掉的部分会淡化显示，点击框外即可确定。“自由排列”时，可拖动图像移动，拖动角落放大、缩小，并设置画布大小。点击的图像会移到最前。裁剪仅用于拼贴，不会更改原图。
- 导出的文件会重新读取，确认格式、尺寸以及没有元数据。保持画质的方式还会确认像素没有变化。
- 开启“保存删除前的元数据以便恢复”时，会将原图的元数据与导出的文件关联保存。

## 复制与粘贴

Ctrl+C 复制编辑结果，Ctrl+V（或“文件 → 打开剪贴板中的图像”）在新标签页中打开剪贴板图像。两者都不包含元数据。输入文字时以文字的复制和粘贴优先。
粘贴的图像以手动保存开始，首次保存时选择保存位置。为了恢复标签页，图像会保存在与设置相同位置的 `clipboard-images` 中。不再需要时，可在退出应用后删除。

## 编辑项目

“文件 → 保存包含原图的编辑项目”会将原图、加工后的图像和蒙版汇总为 `.sumire` 文件。即使没有原图，也可以重新打开并用橡皮擦撤销加工。
**其中也包含隐藏部分加工前的内容。** 分享时请使用通过普通保存生成的图像。不包含编辑历史。

## 分享（交给 NovelAI 和其他应用）

从图像名称右侧的“分享”中选择。都会以不含元数据的形式交付加工后的图像（包括未保存的加工）。

- **复制图像**：可粘贴到投稿栏或聊天中。
- **拖动交付**：在小窗口中显示要交付的图像，请将其拖到浏览器的投稿栏或聊天应用中。
- **用 NovelAI 图生图**：步骤如下。

1. 选择“分享 → 用 NovelAI 图生图”后，会将图像复制到剪贴板，并在浏览器中打开 NovelAI。
2. 登录 NovelAI，粘贴或从 Sumīre 的窗口拖入图像。
3. 选择“Image2Image”。

不会交付原文件名和提示词。开启“齿轮 → NovelAI 联动”后，可在交付前裁剪和缩小。步骤依据 [NovelAI 的说明](https://docs.novelai.net/en/image/controltools)（英语）。

## 设置

点击右上角的齿轮打开，在左侧选择项目进行更改。左下角的“恢复初始设置”可将所有设置（包括快捷键和编辑预设）恢复为初始状态。管理记录、Windows 右键菜单的注册、最近使用的文件夹和显示语言保持不变。

| 项目 | 内容 |
| --- | --- |
| 保存 | 自动保存、覆盖、用于恢复的元数据、保存到其他文件夹时的格式和保存位置、JPEG 质量（1–100，默认 95） |
| 管理记录 | 切换和删除记录的保存位置 |
| 快捷键 | 更改按键操作 |
| 显示、导入 | 显示语言、导航器、导入文件夹中新增的图像、设置标签后前往下一张、自动分入标签文件夹、退出时的确认、全屏显示 |
| NovelAI 联动 | 交付前的裁剪、缩小 |
| Windows 联动 | 右键菜单的注册与解除 |
| 信息 | 版本、许可证、上次错误的详细信息 |

显示语言在下次启动时生效。

关闭窗口时，会确认是否退出。退出后，撤销、重做的历史和覆盖前保留的原图将被清除。未保存的加工会在退出前保存（自动保存关闭的标签页会逐张确认）。可用“以后不再显示此确认”或设置的“显示、导入”关闭此确认。

设置保存在 `sumire-workspace.json` 中（也可以用环境变量 `SUMIRE_SETTINGS_FILE` 指定位置）。其中包含用于恢复工作的文件夹路径，但不包含图像。删除后恢复为初始设置。

## 从 Windows 右键菜单打开

通过“齿轮 → Windows 联动 → 在右键菜单中添加‘用 Sumīre 打开’”，图像（PNG、JPEG、WebP、BMP）、文件夹和文件夹空白处的右键菜单中会添加“用 Sumīre 打开”。在 Windows 11 中位于“显示更多选项”内。

- 只为当前 Windows 用户注册，不会更改默认应用。可用“解除右键菜单注册”移除。
- 移动 exe 后请重新注册，删除前请先解除。
- Sumīre 正在运行时，会在该窗口中打开。正在处理时，会在完成后打开。
