# 操作指南

各功能的详细说明。想先试用时，请阅读应用内的帮助（F1）或[入门操作](../../sumire/help_docs/zh_CN/USER_GUIDE.md)。按键操作汇总在[快捷键](../../sumire/help_docs/zh_CN/SHORTCUTS.md)中。

## 界面

- 上方：“Sumīre”“文件”和工作标签页。右端为保存方式（“覆盖 · 自动保存 ▾”）、帮助、齿轮（设置）
- 左侧：列表操作（按标签导出、批量删除、重置分拣、撤销整理、“⋯”）、文件夹栏、搜索框、图像列表
- 中央：图像。上方为撤销 / 重做、保存状态、是否有元数据、“删除元数据”、“覆盖并下一张 →”，下方为裁剪、比较、蒙版
- 图像名称右侧：“分享”（用 NovelAI 图生图、复制图像、拖动交付）和“⋯”（覆盖保存、另存为、元数据、超分辨率放大、恢复覆盖前的原图等）
- 右侧：加工工具、“详细设置、其他”（预设、范围扩展、旋转、翻转、色调）、分拣
- 底部：状态显示、显示倍率（可输入数值）、全部、原尺寸

保存状态为“未编辑”“未保存”“正在保存…”“已保存”“保存失败”之一。点击“元数据：有 / 无”可显示元数据的内容。

列表中的每张图像会显示编辑和保存状态、标签、标记以及是否有备注。选择 2 张以上时，列表上方会出现“已选择 N 张”栏，可一起操作。

## 打开

- 文件夹：按名称的自然顺序（1、2、10）列出其中的图像。
- 图像：只列出所选的图像（不添加同一文件夹中的其他图像）。
- 工作中打开时，可以选择添加到当前标签页或在新标签页中打开。
- 列表的“⋯ → 导入文件夹中新增的图像”（默认开启）：新放入当前文件夹的图像会在写入完成后加入列表。
- 初始界面的“最近使用的文件夹”可用右侧的 ✕ 从列表中移除（不会删除文件夹）。

### 在文件夹内移动

在打开一个文件夹的标签页中，列表上方会显示文件夹栏。

- 点击文件夹名称即可进入。用“..（上一级文件夹）”或左侧的箭头返回。
- 标签页打开的文件夹是起点，不能超出起点。从“文件”打开其他文件夹时，该文件夹成为新的起点。
- 当前位置显示为“作品 / 差分”的形式。排序、筛选和当前图像按文件夹分别记住，恢复标签页时会回到原来所在的文件夹。
- 用栏右侧的按钮可新建文件夹。

### 将图像移到文件夹

从列表拖到栏中的文件夹上，或使用右键菜单的“移动到文件夹”。

- 图像数据原样移动。存在同名图像时会添加 `_2` 等，不会覆盖。
- 移到其他驱动器时，会先复制并确认内容，再删除原文件。
- 标签、备注、标记、编辑蒙版和用于恢复的元数据也会一起移动。保存到其他文件夹时的保存记录不会移动，因此在目标位置视为未保存。
- 当前图像有未保存的加工时，会询问是否保存。其他图像有未保存的加工时不会移动。
- 用“撤销上一次整理操作”（Ctrl+Alt+Z）可恢复原状。

## 工作标签页

列表、加工和保存方式在每个标签页中相互独立。

- Ctrl+T：新建标签页 / Ctrl+W：关闭 / Ctrl+Tab、Ctrl+Shift+Tab：切换
- 双击或右键单击标签页可更改名称（最多 60 个字符，留空则使用文件夹名称）
- 关闭有未保存加工的标签页时会询问是否保存（保存失败时不会关闭）。
- 退出时的标签页、排序、筛选和当前图像会在下次启动时恢复。只有显示的标签页才会读取图像。启动时指定了图像或文件夹时，只打开它们。

## 保存

保存方式在首次启动时选择，之后可通过右上角的“覆盖 · 自动保存 ▾”更改。如果不选择就关闭了首次设置界面，则保存到其他文件夹（从 0.4.0 或更早版本开始使用时，保持覆盖、自动保存）。

### 保存位置

- 覆盖保存原图：以相同的位置、名称和格式替换 PNG、JPEG、WebP。其他格式无法覆盖。每次启动后首次覆盖时会显示确认。
- 保存到其他文件夹：保存到原图所在文件夹内的 `Sumīre`。保存位置和格式（PNG、JPEG、无损 WebP）可以更改。

### 保存方式的选项

- 临时保留覆盖前的原图（默认开启）：首次覆盖前的原图会保留到应用退出。通过“⋯ → 恢复覆盖前的原图”可连同元数据恢复。
- 保存时删除元数据（默认关闭）：关闭时保留原图的元数据（以其他格式保存时除外）。“删除元数据”和批量删除始终会删除。
- 自动保存：开启时每次涂抹都会保存。关闭时，切换到其他图像时会询问是否保存。

### 保存的时机

- 未加工的图像仅切换不会保存。按 Enter（保存并下一张）时会保存。
- 即使保存失败，加工也会保留。
- 保存过程中继续加工时，会在前一次保存完成后保存最新状态。

保存的机制和检查内容见[保存与隐私](SAVING_AND_PRIVACY.md)。

## 加工

### 工具

- 马赛克：强度为色块大小。用 `,` 和 `.` 以 2px 为单位调整。
- 模糊：强度为模糊半径。
- 填充：选择颜色和不透明度（0–100%）。100% 时完全替换原像素。
- 橡皮擦：将涂抹的部分恢复为原图。再按一次（E）返回原来的工具。
- 文本：在图像中添加文字。再按一次（T）返回原来的工具（见下文“文字”）。

### 指定范围

- 形状：画笔、矩形、椭圆、多边形、套索。将鼠标悬停在选择栏上可查看用法。
- 多边形：单击添加顶点，按 Enter 或双击确定。Backspace 撤回顶点，Esc 取消。
- 套索：拖动圈选。应用于线条交叉形成的第一个闭合区域（没有交叉时不进行任何操作）。
- 应用于外侧：开启“⋯ → 其他 → 反选”后，加工下一次圈选范围的外侧（画笔除外）。
- 范围扩展：将范围向外扩展 0–3px（默认 1px），防止轮廓边缘残留未加工的部分。
- 画笔直径、强度和范围扩展也可在名称右侧的栏中输入数值。

### 其他操作

- Alt+单击：吸管 / Shift+单击：从上一个画笔位置画直线
- 按住“比较”或 Tab：显示原图
- “蒙版”（M）：用蓝色显示加工范围（不会保存）
- “重置加工、蒙版”：清除所有加工。可用 Ctrl+Z 撤销。
- 编辑预设：为工具、大小、强度、颜色、形状和范围扩展命名并保存（“详细设置、其他”）。

### 文字

选择“文本”（T）后点击图像，会打开添加文字的窗口。

- 选择文字（可换行）、字体、大小（原图像素）、颜色和粗体。输入时会在图像上显示效果。
- 点击的位置为第 1 行的左上角。
- 点击“添加”后写入图像。与其他加工相同，可用橡皮擦清除、在蒙版中显示并保存。
- 选择的字体、大小、颜色和粗体也会用于下一次的文字。
- 文字工具无法登记为编辑预设。

添加的文字会带有框。选择文字工具期间可进行以下操作：

- 拖动框内：移动
- 拖动角：缩放（对角保持不动）
- 拖动上方的圆点：旋转（按住 Shift 以 15° 为单位）
- 双击框：重写（追加文字，更改字体、大小或颜色；左上角位置不变）
- Delete：删除
- 点击框外或按 Esc：取消选择（下一次点击添加新文字）

以上操作都会立即写入图像，可用“撤销”逐步返回，框也会回到当时的位置。进行其他加工后，该文字无法再通过框编辑（用“撤销”返回后即可再次编辑）。

加工范围（蒙版）会保存在管理记录中，重新打开图像时恢复。图像被其他应用更改时不会使用。通过“⋯ → 其他 → 将编辑蒙版保存为 PNG”可导出为黑白 PNG。

## 裁剪、旋转、色调、超分辨率放大

- 裁剪：图像下方的“裁剪”。拖动四角或边缘缩小范围，拖动框内移动。也可输入数值，“指定输出尺寸”可放大或缩小。
- 旋转、翻转：“详细设置、其他”中的按钮，点击即可应用。
- 色调：“详细设置、其他”中的“调整色调”。亮度、对比度、饱和度、色相、曝光、色温、伽马，以及“详细调整”中的高光、阴影、白色 / 黑色色阶、RGB 平衡、锐度。双击滑块恢复初始值。
- 超分辨率放大：“⋯ → 其他 → 超分辨率放大”。放大 1.5–4 倍（每边最多 32,768 px、2400 万像素）。隐藏的部分不会被恢复。

以上操作都会同时更改图像和蒙版，可用“撤销”恢复。覆盖保存设置下，裁剪和超分辨率放大前会确认。覆盖保存并退出后，裁掉的部分无法恢复。

## 分拣

### 标签

- 用右下角的“采用”“待定”“不采用”（1、2、3）设置。再按一次也不会取消，用 Alt+0 取消。
- 多选时会一起设置（Ctrl+单击逐张添加或取消，Shift+单击选择范围）。
- 开启“设置标签后前往下一张”（默认开启）时，每次设置标签都会前往下一张。
- 用筛选按钮可按标签筛选。“重置分拣”会清除标签页中的所有标签。

标签会立即保存，重启、重命名和移动后仍会保留，不会改变图像内容。

### 标记

- 右键菜单的“标记…”可自由添加或移除标记（多选时一起）。
- 勾选为添加，取消勾选为移除，半勾选保持不变。
- 标记显示在列表的第 2 行。可用“按标记筛选”和搜索查找。

### 自定义标记

常用的标记可作为按钮排在分拣栏的“自定义标记”中。初始为“需修正”。它位于采用、待定、不采用标签的上方，点击标题可展开或收起（初始为收起）。

- 按下按钮，会为当前（或所选）图像添加该标记；全部都已有时则移除。
- 从上往下也可用 4–9 键操作（可在快捷键设置中更改）。
- 用“编辑”可添加、重命名、删除和排序（最多 9 个）。重命名时，此标签页图像上的同名标记也会一并更改（可关闭）。
- 删除只会移除按钮，图像上已有的标记会保留。
- 添加和移除可通过“撤销上一次整理操作”撤回。按钮在所有标签页中通用。

### 标签文件夹

- 自动分入：在右键的“标签”或设置 → 显示、导入 → 分拣中开启。在有采用、待定、不采用文件夹的位置，加上标签的图像会立即移入对应文件夹（在“待定”中改为采用会移到旁边的“采用”）。
- 按标签导出：将所选标签的图像移入以标签命名的文件夹，并重新编号为 00, 01…。关闭“移动原图文件”时，原图不变，将编辑后的图像不带元数据导出。保存位置、编号和格式可以更改。
- 汇总标签文件夹：从列表的“⋯”中使用。将采用、待定、不采用文件夹的图像汇总到一个文件夹，可删除变空的文件夹。

标签、备注和标记会一起移动，可通过“撤销上一次整理操作”撤回。移动原图前，请先保存未保存的加工。

### 将列表恢复为初始状态

列表的“⋯ → 将列表恢复为初始状态”会一起恢复：

- 本次启动中保留了原图的覆盖
- 当前图像的加工和蒙版
- 标签、备注、标记、排序、筛选和搜索

本次启动前保存的加工，以及未保留原图的覆盖无法恢复。

## 整理

- 搜索（Ctrl+F）：输入文件名、备注或标记的一部分。
- 排序：按名称或按修改时间。拖动图像会变为手动顺序，靠近列表边缘时会滚动。
- 重命名：双击图像名称或按 F2。扩展名不会改变。
- 编号：列表的“⋯ → 按顺序重新编号”或右键菜单。按列表顺序从 0 开始，位数比最大编号多一位（3 张为 00–02）。
- 备注：右键菜单的“备注”（最多 4000 个字符）。将鼠标悬停在列表中的图像上即可阅读。
- 从列表中移除：右键菜单。不会删除文件，Ctrl+R 可恢复。
- 删除图像：右键菜单的“删除图像…”。移到回收站。
- 删除重复：列表的“⋯ → 删除重复”。每组内容相同的图像保留一张，其余移到回收站。
- 比较：选择 2–6 张，右键菜单的“并排比较多张”。“联动缩放与移动”可保持显示一致。

列表上方的箭头（“撤销上一次整理操作”，Ctrl+Alt+Z）会从新到旧撤销标签、标记、排序、名称、备注和移动。

重命名不会重写图像。

- 目标位置存在同名文件时会中止。
- 管理记录（保存记录、标签、备注、标记、蒙版）会在同一步骤中更新。无法更新时会取消整个重命名。
- 中途停止时，下次打开时可以恢复原名称或确定更改。

## 导出

- 另存为：“⋯”或右键菜单。选择名称和格式保存为新文件。
- 转换格式：右键菜单或列表的“⋯”。转换为 PNG、JPEG、WebP、AVIF、BMP、TIFF、GIF。
- 压缩体积：右键菜单或列表的“⋯”。减小文件。
- 创建拼贴：选择图像后右键菜单的“创建拼贴”。

转换格式和压缩体积不会更改原图，会导出到“已转换”“已压缩”文件夹（保存位置可以更改）。不会覆盖同名文件。

### 压缩体积

- 保持画质：PNG 优化（256 色以下转换为调色板）、WebP 无损压缩
- 可能降低画质：JPEG、WebP、AVIF、PNG 减色
- 选择方式时会实际转换第 1 张并显示结果，例如“原图 3.2 MB → 压缩后 740 KB（减少 77%）”。
- 也可缩小长边。取消则不留下任何文件。
- “覆盖原图”：仅替换格式不变的图像（原图会保留到应用退出）。

JPEG 和 BMP 会将透明部分变为白色，GIF 为 256 色。不支持 HEIC。

导出的文件会重新读取，确认格式、尺寸以及没有元数据。开启“保存删除前的元数据以便恢复”时，会将原图的元数据与导出的文件关联保存。

### 拼贴

- 将 1–16 张图像按网格（左右、上下、2×2 等）或自由排列合成为 1 张。可用“添加图像…”“移除”改变张数。
- 双击图像显示裁剪框，点击框外确定（不会更改原图）。
- “自由排列”时，可拖动移动、拖动角落缩放，并设置画布大小。

## 复制与粘贴

- Ctrl+C：复制编辑结果（不含元数据）
- Ctrl+V（“文件 → 打开剪贴板中的图像”）：在新标签页中打开剪贴板图像
- 在列表中时，Ctrl+X、Ctrl+C、Ctrl+V 为剪切、复制、粘贴图像文件（粘贴到标签页文件夹，也可与资源管理器互通）。
- 输入文字时以文字的复制和粘贴优先。

粘贴的图像以手动保存开始，首次保存时选择保存位置。为了恢复标签页，会保存在与设置相同位置的 `clipboard-images` 中（可在退出应用后删除）。

## 编辑项目

“文件 → 保存包含原图的编辑项目”会将原图、加工后的图像和蒙版汇总为 `.sumire` 文件。重新打开后可用橡皮擦撤销加工（不包含编辑历史）。

其中也包含隐藏部分加工前的内容，因此分享时请使用通过普通保存生成的图像。

## 分享

从图像名称右侧的“分享”交付加工后的图像（包括未保存的加工）。

- 复制图像：粘贴到投稿栏或聊天中。
- 拖动交付：将小窗口中的图像拖到浏览器或聊天应用中。
- 用 NovelAI 图生图：步骤见下文。

复制和拖动都不包含元数据。

### 用 NovelAI 图生图

1. 选择“分享 → 用 NovelAI 图生图”后，会将图像复制到剪贴板，并在浏览器中打开 NovelAI。
2. 登录 NovelAI，粘贴或从 Sumīre 的窗口拖入图像。
3. 选择“Image2Image”。

在“齿轮 → NovelAI 联动”中可选择交付前的裁剪和缩小。

开启“交给 NovelAI 的图像附带生成信息（元数据）”（默认关闭）后，仅在原图为 PNG 时附带生成信息（PNG 文本和 Stealth PNGInfo）。NovelAI 的界面能否实际读取，尚未确认。

不会交付原文件名。步骤依据 [NovelAI 的说明](https://docs.novelai.net/en/image/controltools)（英语）。

## 设置

点击右上角的齿轮打开。

- 保存：自动保存、覆盖、用于恢复的元数据、保存到其他文件夹时的格式和保存位置、JPEG 质量（1–100，默认 95）
- 管理记录：切换和删除记录的保存位置
- 快捷键：更改按键操作
- 显示、导入：显示语言（下次启动时生效）、导航器、导入新增的图像、设置标签后前往下一张、自动分入标签文件夹、退出时的确认、全屏显示
- NovelAI 联动：交付前的裁剪、缩小，附带生成信息
- Windows 联动：右键菜单的注册与解除
- 信息：版本、许可证、上次错误的详细信息

左下角的“恢复初始设置”可将所有设置（包括快捷键和编辑预设）恢复为初始状态。管理记录、右键菜单的注册、最近使用的文件夹和显示语言保持不变。

### 退出时

- 关闭窗口时会确认是否退出（可用“以后不再显示此确认”或设置的“显示、导入”关闭）。
- 未保存的加工会在退出前保存（自动保存关闭的标签页会逐张确认）。
- 退出后，撤销、重做的历史和覆盖前保留的原图将被清除。

设置保存在 `sumire-workspace.json` 中（也可用环境变量 `SUMIRE_SETTINGS_FILE` 指定位置）。包含文件夹路径，但不包含图像。删除后恢复为初始设置。

## 从 Windows 右键菜单打开

通过“齿轮 → Windows 联动 → 在右键菜单中添加‘用 Sumīre 打开’”，图像（PNG、JPEG、WebP、BMP）、文件夹和文件夹空白处的右键菜单中会添加“用 Sumīre 打开”。在 Windows 11 中位于“显示更多选项”内。

- 只为当前 Windows 用户注册，不会更改默认应用。
- 移动 exe 后请重新注册，删除前请用“解除右键菜单注册”解除。
- Sumīre 正在运行时，会在该窗口中打开。
