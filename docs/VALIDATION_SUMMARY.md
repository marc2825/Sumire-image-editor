# 動作確認

どこまで確認済みかをまとめています。検証には合成画像だけを使い、利用者の画像は使っていません。

## 1.01.0 で確認したこと（2026-11-13）

Windows 11 Pro x64（25H2、日本語）の PC 1台で、公開用のソースからビルドした配布 ZIP を使って確認しました。この PC には Python が入っています。「Linux」とある項目は開発環境（WSL）での確認です。

## 以前の版で確認したこと

配布版 0.4.0（2026-11-09）で、Windows 上の実際の操作（描画・自動保存・元に戻す／やり直す・メタデータの復元）、右クリックからの起動と起動中の画面への受け渡し、200% 相当の表示を確認しました。PNG・JPEG・WebP のメタデータ削除は ExifTool でも確認しました（Linux）。

## まだ確認していないこと

- Python を入れたことのない PC での起動
- Windows の表示倍率そのものを 125%・150% に変えた状態
- 実際のマウス・キーボードでの操作（作業タブ、ラベルごとの書き出し、フォルダー間の移動、ごみ箱への移動、コラージュ、投げ縄、ドラッグ中のカーソル、ブラウザーやチャットへのドラッグ、終了の確認など）
- 実際のカメラ・スマートフォンの画像（JPEG の埋め込みサムネイルなど）と、実際に生成された NovelAI の画像
- ブラウザーでの NovelAI への取り込み
- 右クリックからの起動と、`sumire.exe --unregister` による実際の解除
- Microsoft Defender での検査（確認に使った PC では Defender が無効）と、ダウンロードしたファイルを初めて起動したときの SmartScreen の表示
- 停電など、強制終了以外の中断からの復旧

## 制限

- 元画像に上書きする設定では、置き換える前の元画像をアプリの終了までしか残しません。
- モザイクやぼかしでは完全には隠せません。確実に隠す部分は、不透明度100%で塗りつぶしてください。
- 「メタデータ：無し」は、対応している形式を調べた結果です。未知の方法で埋め込まれた情報までは確認できません。
- JPEGは保存のたびに圧縮し直すため、画素がわずかに変わります。
- 編集の履歴は終了すると消えます。
- ハードリンクを使えない保存先（一部のネットワークドライブなど）には保存できないことがあります。ローカルのNTFSフォルダーをお勧めします。
- ほかのアプリが同じファイルを同時に書き換えることは防げません。
- コード署名がないため、初回の起動時にWindowsの警告が出ることがあります。
