# Python 3.12.10

Windows版には Python 3.12.10（64 ビット）のランタイムが入っています。

- `LICENSE.txt`：ビルドに使った Python に付属するライセンス（PSF License、Windows版の追加条件、bzip2・libffi・OpenSSL・Tcl/Tk の通知）。配布物を作るときに `scripts/package_windows.py` がビルド環境からコピーします。
- `python-3.12.10-license.rst.txt`：CPython 3.12.10 の `Doc/license.rst`（[v3.12.10 のタグ](https://github.com/python/cpython/blob/v3.12.10/Doc/license.rst)から取得、改変なし）。Python に組み込まれている expat・libmpdec・zlib・SipHash などの通知（Licenses and Acknowledgements for Incorporated Software）を含みます。
