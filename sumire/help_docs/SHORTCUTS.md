# ショートカット

初期設定のキーです。右上の「歯車 → ショートカット」で変更できます（1つの操作に2つまで。同じキーを2つの操作には割り当てられません）。画像を操作するキーは、画像の表示部分を選んだ状態で使います。文字の入力中は入力が優先されます。

| 操作 | キー |
| --- | --- |
| フォルダーを開く | Ctrl+O |
| 「ファイル」メニュー | Alt+F |
| 一覧を読み直す（外した画像も戻る） | Ctrl+R |
| 保存 | Ctrl+S |
| 前／次の画像 | ←／→ |
| 保存して次へ（加工していなくても保存） | Enter |
| 元に戻す／やり直す | Ctrl+Z／Ctrl+Y（Ctrl+Shift+Z） |
| 新しいタブ／タブを閉じる | Ctrl+T／Ctrl+W |
| 次／前のタブ | Ctrl+Tab／Ctrl+Shift+Tab |
| 名前を変える | F2、画像名のダブルクリック |
| 名前・メモ・タグで検索 | Ctrl+F |
| 採用／保留／不採用 | 1／2／3 |
| ラベルを外す | Alt+0 |
| 直前の整理操作を戻す | Ctrl+Alt+Z |
| 消しゴムの切り替え | E |
| マスクの表示 | M |
| 元画像と比較 | Tab（押している間） |
| 拡大・縮小 | ホイール／+／−。右下の倍率に数値を入れてEnterでも変えられます |
| 表示位置を動かす | Space＋ドラッグ／中ボタンでドラッグ |
| 全体表示／原寸 | F／Ctrl+1 |
| ブラシを小さく／大きく | [／] |
| 強さを弱く／強く | ,／. |
| なぞっている途中で取り消す | Esc |
| ヘルプ | F1 |
| コピー（一覧では画像ファイル、ほかでは編集結果） | Ctrl+C |
| 画像ファイルを切り取る | Ctrl+X |
| 貼り付け（画像ファイルはタブのフォルダーへ、画像は新しく開く） | Ctrl+V |
| 全画面表示 | F11 |

## 変更できない操作

| 操作 | キー |
| --- | --- |
| スポイト | Alt＋クリック |
| 直前のブラシ位置から直線 | Shift＋クリック |
| 多角形の頂点を追加／確定 | クリック／Enter・ダブルクリック |
| 最後の頂点を消す／中止 | Backspace／Esc |
| 名前の確定／取り消し | Enter／Esc |

「元に戻す」で戻るのは画像の加工だけです。ラベル・タグ・並び順・名前・メモ・フォルダーの移動は「直前の整理操作を戻す」で戻します。
