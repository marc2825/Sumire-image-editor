# 快捷键

以下为默认按键。可在右上角的“齿轮 → 快捷键”中更改（每个操作最多 2 个键，同一个键不能分配给两个操作）。作用于图像的按键需在选中图像显示区域时使用。输入文字时以输入优先。

| 操作 | 按键 |
| --- | --- |
| 打开文件夹 | Ctrl+O |
| “文件”菜单 | Alt+F |
| 重新加载列表（移除的图像也会恢复） | Ctrl+R |
| 保存 | Ctrl+S |
| 上一张 / 下一张图像 | ← / → |
| 保存并下一张（未加工也会保存） | Enter |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z） |
| 新建标签页 / 关闭标签页 | Ctrl+T / Ctrl+W |
| 下一个 / 上一个标签页 | Ctrl+Tab / Ctrl+Shift+Tab |
| 重命名 | F2，或双击图像名称 |
| 按名称、备注、标记搜索 | Ctrl+F |
| 采用 / 待定 / 不采用 | 1 / 2 / 3 |
| 取消标签 | Alt+0 |
| 撤销上一次整理操作 | Ctrl+Alt+Z |
| 切换橡皮擦 | E |
| 显示蒙版 | M |
| 与原图比较 | Tab（按住期间） |
| 放大、缩小 | 滚轮 / + / −。也可在右下角的倍率中输入数值后按 Enter |
| 移动显示位置 | 空格键＋拖动 / 用中键拖动 |
| 适合窗口 / 原尺寸 | F / Ctrl+1 |
| 缩小 / 放大画笔 | [ / ] |
| 减弱 / 增强 | , / . |
| 涂抹途中取消 | Esc |
| 帮助 | F1 |
| 复制（列表中为图像文件，其他位置为编辑结果） | Ctrl+C |
| 剪切图像文件 | Ctrl+X |
| 粘贴（图像文件粘贴到标签页文件夹，图像则新建打开） | Ctrl+V |
| 全屏显示 | F11 |

## 无法更改的操作

| 操作 | 按键 |
| --- | --- |
| 吸管 | Alt＋单击 |
| 从上一个画笔位置画直线 | Shift＋单击 |
| 添加多边形顶点 / 确定 | 单击 / Enter 或双击 |
| 删除最后一个顶点 / 取消 | Backspace / Esc |
| 确认 / 取消名称 | Enter / Esc |

“撤销”只撤销图像的加工。标签、标记、排序、名称、备注和文件夹移动请用“撤销上一次整理操作”撤销。
