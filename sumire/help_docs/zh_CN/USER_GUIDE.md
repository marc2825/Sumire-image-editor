# 入门操作

基本流程是“打开 → 涂抹加工 → 保存 → 下一张图像”。

## 1. 打开

使用初始界面的“打开文件夹”“打开图像”，或拖放来打开。工作中可从左上角的“文件”（Alt+F）打开。

- 打开文件夹后，列表中会显示其中的图像。内部的文件夹可从列表上方的栏位打开（参见[在文件夹之间移动](#在文件夹之间移动)）。
- 选择图像打开时，只显示这些图像。
- 工作中打开时，可以选择添加到当前标签页或在新标签页中打开。
- 通过“文件 → 打开 ZIP…”或拖放 ZIP，无需解压即可查看其中的图像（在新标签页中打开，只读）。

下次启动时，会从上次的标签页和工作位置继续。

## 2. 选择保存方式

首次启动时，选择“覆盖保存原图”或“保存到其他文件夹并保留原图”。如果不选择就关闭该窗口，将保存到其他文件夹。

之后可通过右上角的“覆盖 · 自动保存 ▾”更改以下项目：

- 覆盖保存原图：关闭后保留原图，保存到其他文件夹。
- 临时保留覆盖前的原图（默认开启）：通过右侧面板最下方的“恢复覆盖前”，可恢复到首次覆盖前的状态。保留的原图会在应用退出时删除。
- 自动保存：关闭后用 Ctrl+S 手动保存。
- 保存时删除元数据（默认关闭）：开启后每次保存都删除元数据。
- 保存删除前的元数据以便恢复（默认开启）：保留删除的元数据，以便之后恢复。

即使保存失败，编辑也会保留。请确认显示的原因后再次保存。

## 3. 隐藏

在右侧面板选择马赛克、模糊或填充，然后涂抹要隐藏的部分。除画笔外，还可以用矩形、椭圆、多边形、套索指定范围。

- Ctrl+Z / Ctrl+Y：撤销 / 重做
- 橡皮擦（E）：将涂抹的部分恢复为原图。再按一次返回原来的工具。
- 比较：按住图像下方的“比较”或 Tab 期间显示原图。
- 蒙版：在加工范围上叠加颜色显示（不会保存）。
- 重置加工、蒙版：清除所有加工。可用 Ctrl+Z 撤销。
- 长边的 1/100（马赛克时）：将马赛克每格设为图像长边的 1/100（向上取整）。开启期间每切换一张图像都会重新设置，手动更改强度后将关闭。
- 将加工范围复制到其他图像（“⋯”或右键菜单）：将当前图像中加工过的范围复制到所选图像或列表中其他图像的相同位置，用马赛克、模糊或填充加工并保存。大小不同的图像会复制到相同比例的位置。

要添加文字时，选择“文本”（T）后点击图像。在打开的窗口中选择文字、字体、大小、颜色和粗体，可在图像上确认效果。点击的位置为文字的左上角。

添加的文字带有框：拖动框内移动，拖动角缩放，拖动上方的圆点旋转，双击重写，按 Delete 删除。每次都可用“撤销”返回一步。

## 4. 下一张图像

- 用 ← → 键切换前后图像。未加工的图像仅切换不会保存。
- 按 Enter 会保存图像（即使未加工）并前往下一张。
- 自动保存关闭时，切换前会询问是否保存。

## 5. 查看与删除元数据

点击图像上方的“元数据：有 / 无”，会按类型显示图像包含的信息。

默认情况下，保存时会保留元数据。删除时请使用：

- 当前图像：图像上方的“删除元数据”
- 标签页中的所有图像：列表下方的“导出和批量处理 → 批量删除所有图像的元数据…”（执行前会确认张数和保存方式）
- 所选图像：列表右键菜单的“删除元数据并保存”
- 每次保存时：开启“保存时删除元数据”

另请参阅[元数据与恢复](METADATA.md)。

## 6. 分拣

### 标签与标记

- 用图像下方的“采用”“待定”“不采用”（1、2、3 键）设置标签。用 Alt+0 取消。
- 开启“设置后下一张”（默认开启）时，设置后会进入下一张。
- 按住 Ctrl 或 Shift 多选后可一起设置。
- 右键菜单的“标记…”可在标签之外自由添加标记。
- 常用的标记（自定义标记）可用标签右侧的按钮添加或移除（初始为“需修正”，从左往右对应 4–9 键）。用其右侧的标记图标可添加、重命名、删除和排序。

设置标签不会删除图像。

### 标签文件夹

- 按标签导出（列表下方的“导出和批量处理”）：将所选标签的图像移入以标签命名的文件夹，并重新编号为 00, 01…。关闭“移动原图文件”时，原图不变，改为导出不含元数据的编辑结果。
- 自动分入：在右键的“标签”或设置 → 显示、导入 → 分拣中开启。在有采用、待定、不采用文件夹的位置，加上标签的图像会立即移入对应文件夹（将鼠标停在该选项上可查看详细规则）。

### 整理列表

- 重置全部分拣（列表下方的“导出和批量处理”）：清除所有标签。
- 列表上方的“撤销整理”（Ctrl+Alt+Z）：撤销标签、标记、排序、名称、备注和移动。
- 重新排序：拖动列表中的图像。排序方式可用搜索框右侧的按钮更改。
- 重命名：双击图像名称或按 F2（Enter 确认，Esc 取消）。
- 编号：列表下方的“导出和批量处理 → 按顺序重新编号”或右键菜单。按列表顺序编号为 00, 01…。
- 删除重复：列表下方的“导出和批量处理 → 删除重复”。内容相同的图像保留一张，其余移到回收站。
- 从列表中移除：右键菜单。不会删除文件，Ctrl+R（或文件夹栏的 ⟳）可恢复。
- 删除图像：右键菜单的“删除图像…”。移到回收站（可从回收站还原）。
- 查找：在搜索框中输入文件名、备注或标记的一部分。修改图像上方“4 / 111”中的编号并按 Enter，可跳转到该图像。

## 在文件夹之间移动

在打开文件夹的标签页中，列表上方会显示文件夹栏。

- 点击文件夹名称即可进入。用“..（上一级文件夹）”或左侧的箭头返回（不能超出标签页打开的文件夹）。
- 用栏右侧的按钮可以新建文件夹。
- 将图像拖到栏中的文件夹上，或使用右键菜单的“移动到文件夹”即可移动。存在同名图像时会添加 `_2` 等，不会覆盖。标签、备注和标记也会一起移动。

## 标签页

- Ctrl+T：新建标签页 / Ctrl+W：关闭 / Ctrl+Tab、Ctrl+Shift+Tab：切换
- 双击标签页可更改名称（留空则使用文件夹名称）。
- 关闭所有标签页后返回初始界面。

## 之后继续加工

“文件 → 保存包含原图的编辑项目”可将原图、加工后的图像和蒙版一起保存（不包含编辑历史）。

其中包含加工前的内容，请不要与完成的图像一起分享。

## 裁剪、旋转、色调

- 裁剪：右侧面板“调整图像”中的“裁剪和更改尺寸…”。拖动四角或边缘确定范围，拖动框内移动。也可输入数值，“指定输出尺寸”可放大或缩小。
- 旋转、翻转：“调整图像”中的按钮，点击即可应用。
- 色调：同一位置的“调整色调…”。“详细调整”中还有高光、阴影、白色 / 黑色色阶、RGB 平衡、锐度。

以上操作都可以“撤销”。覆盖保存设置下，裁剪前会确认。

## 另存为、转换、压缩体积、超分辨率放大

图像上方的“⋯”和图像右键菜单中有常用操作。

- 覆盖保存（Ctrl+S）：以当前保存方式保存（保存到其他文件夹时显示为“保存”）。
- 另存为：选择名称和格式，保存为新文件。
- 删除元数据并保存 / 查看元数据内容
- 其他 → 超分辨率放大：放大 1.5–4 倍。隐藏的部分不会被恢复。
- 恢复覆盖前的原图：恢复为本次启动中首次覆盖前的状态。

转换格式和压缩体积在右键菜单中（整个列表请用列表下方的“导出和批量处理”）。

- 原图保持不变，导出到新文件夹。
- 压缩体积会先显示结果，例如“原图 3.2 MB → 压缩后 740 KB（减少 77%）”。
- 在压缩体积中选择“覆盖原图”时，仅替换格式不变的图像（原图会保留到应用退出）。
- 文件大小上限：设定每张的上限（KB）后，有损格式会先降低画质，仍然过大时再缩小图像。
- 添加水印、签名：将文字或签名图像放在角落、中央或整体（斜向重复）。大小为相对长边的比例，可预览。只加在导出的图像上，原图不变。

选择 2 张以上时，右键菜单中可使用“并排比较多张”（最多 6 张）。“创建拼贴”从 1 张起即可，可网格排列或自由排列，双击图像可裁剪。

## 复制与粘贴

- Ctrl+C：复制编辑结果（不含元数据）
- Ctrl+V：在新标签页中打开剪贴板图像
- 在列表中时：Ctrl+X、Ctrl+C、Ctrl+V 可剪切、复制、粘贴图像文件本身（也可与资源管理器互通）

粘贴的图像会保存在与设置相同位置的 `clipboard-images` 中（可在退出应用后删除）。

## 交给 NovelAI 或其他应用

使用图像上方的分享按钮。

- 复制图像 / 拖动交付：将不含元数据的图像交给社交网站或聊天应用。
- 用 NovelAI 图生图：复制图像并在浏览器中打开 NovelAI。粘贴或拖入后，选择“Image2Image”。

交给 NovelAI 的图像默认也不含元数据。在“齿轮 → NovelAI 联动”中开启附带生成信息后，原图为 PNG 时会附带。

## 设置

点击右上角的齿轮打开。

- JPEG 质量：“保存”
- 按键分配：“快捷键”
- 导航器、全屏显示（F11）、显示语言：“显示、导入”

左下角的“恢复初始设置”可将所有设置恢复为初始状态。
