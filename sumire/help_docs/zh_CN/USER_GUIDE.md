# 入门操作

基本流程是“打开 → 涂抹加工 → 保存 → 下一张图像”。

## 1. 打开

使用初始界面的“打开文件夹”“打开图像”，或拖放来打开。工作中可从左上角的“文件”（Alt+F）打开。下次启动时，会从上次的标签页和工作位置继续。

- 打开文件夹后，列表中会显示其中的图像。内部的文件夹可从列表上方的栏位打开（参见[在文件夹之间移动](#在文件夹之间移动)）。
- 选择图像打开时，只显示这些图像。
- 工作中打开时，可以选择添加到当前标签页或在新标签页中打开。

## 2. 选择保存方式

首次启动时，选择“覆盖保存原图”或“保存到其他文件夹并保留原图”。之后随时可通过右上角的“覆盖 · 自动保存 ▾”更改。如果不选择就关闭该窗口，将设为覆盖并自动保存。首次覆盖时会显示确认。

- 保留原图：关闭“覆盖保存原图”。
- 能撤销覆盖：开启“临时保留覆盖前的原图”（默认开启）。通过图像上方的“恢复覆盖前”（或“⋯ → 恢复覆盖前的原图”），可以恢复到本次启动中首次覆盖前的状态。**保留的原图会在应用退出时删除。**
- 手动保存：关闭“自动保存”，用 Ctrl+S 保存。
- 每次保存都删除元数据：开启“保存时删除元数据”（默认关闭，元数据会保留）。
- 能恢复删除的元数据：开启“保存删除前的元数据以便恢复”（默认开启）。

即使保存失败，编辑也会保留。请确认显示的原因后再次保存。

## 3. 隐藏

在右侧面板选择马赛克、模糊或填充，然后涂抹要隐藏的部分。除画笔外，还可以用矩形、椭圆、多边形、套索指定范围。

- 撤销：Ctrl+Z。重做：Ctrl+Y。
- 橡皮擦：将涂抹的部分恢复为原图。再按一次（E）返回原来的工具。
- 比较：按住图像下方的“比较”或 Tab 期间显示原图。
- 蒙版：在加工范围上叠加颜色显示。此颜色不会保存。
- 重置加工、蒙版：确认后清除所有加工，恢复为原图。可用 Ctrl+Z 撤销。

## 4. 下一张图像

用 ← → 键切换前后图像。未加工的图像仅切换不会保存。
按 Enter 会保存图像（即使未加工）并前往下一张。
自动保存关闭时，切换图像会询问是否保存。

## 5. 查看与删除元数据

点击图像上方的“元数据：有 / 无”，会按类型显示图像包含的信息（“[类型] 项目：内容”的形式，无法解读的信息显示为“未知”）。

默认情况下，保存时会保留元数据。删除时请使用：

- 当前图像：图像上方的“删除元数据”
- 标签页中的所有图像：列表上方的“批量删除元数据”。执行前会确认张数和保存方式。
- 所选图像：列表右键菜单的“删除元数据并保存”

如需每次保存时删除，请开启“保存时删除元数据”。另请参阅[元数据与恢复](METADATA.md)。

## 6. 分拣

用右下角的“采用”“待定”“不采用”（1、2、3 键）设置标签。设置后会进入下一张（可用“设置标签后前往下一张”开关）。设置标签不会删除图像。按住 Ctrl 或 Shift 多选后可一起设置。

- 按标签分开：列表上方的“按标签导出”。选择采用、待定、不采用之一或所有标签后，会在当前文件夹中创建以标签命名的文件夹，并重新编号为 00, 01… 移入。关闭“移动原图文件”时，原图不变，改为导出删除元数据后的编辑结果。保存位置和是否编号都可更改。
- 清除所有标签：列表上方的“重置分拣”。
- 撤销上一次整理：列表上方的箭头（Ctrl+Alt+Z）。可撤销标签、排序、名称、备注和文件夹移动。
- 重新排序：拖动列表中的图像。排序方式可用搜索框右侧的按钮更改。
- 重命名：双击图像名称或按 F2。Enter 确认，Esc 取消。
- 编号：列表的“⋯ → 按顺序重新编号”或右键菜单。按列表顺序编号，位数比最大编号多一位（3 张为 00–02）。
- 删除重复：列表的“⋯ → 删除重复”。内容相同的图像中，保留一张，其余移到回收站。
- 从列表中移除：右键菜单的“从列表中移除”。不会删除文件，Ctrl+R（或文件夹栏的 ⟳）可恢复。
- 查找：在搜索框中输入文件名或备注的一部分。修改图像上方“4 / 111”中的编号并按 Enter，可跳转到该图像。

## 在文件夹之间移动

在打开文件夹的标签页中，列表上方会显示文件夹栏。

- 点击文件夹名称即可切换到该文件夹的图像。用“..（上一级文件夹）”或左侧的箭头返回。不能超出标签页打开的文件夹。
- 用栏右侧的按钮可以新建文件夹。
- 将图像拖到栏中的文件夹上，或使用右键菜单的“移动到文件夹”即可移动。存在同名图像时会添加 `_2` 等，不会覆盖。标签和备注也会一起移动。

## 标签页

Ctrl+T 新建标签页，Ctrl+W 关闭，Ctrl+Tab / Ctrl+Shift+Tab 切换。关闭所有标签页后返回初始界面。
双击标签页可更改名称。留空则恢复为文件夹名称。

## 之后继续加工

“文件 → 保存包含原图的编辑项目”可将原图、加工后的图像和蒙版一起保存。
**其中包含加工前的内容，请不要与完成的图像一起分享。** 编辑历史不会保存。

## 裁剪、旋转、色调

- 裁剪：图像下方的“裁剪”。框一开始围住整个图像。拖动四角或边缘调整范围，拖动框内可移动。也可以输入数值。“指定输出尺寸”可放大或缩小。
- 旋转、翻转：右侧面板“详细设置、其他”中的按钮，点击即可应用。
- 色调：同一位置的“调整色调”。可更改亮度、对比度、饱和度、色相、曝光、色温、伽马，打开“详细调整”还可使用高光、阴影、白色 / 黑色色阶、RGB 平衡、锐度。窗口内的“撤销”“重做”（Ctrl+Z / Ctrl+Y）可逐步返回。

以上操作都可以“撤销”。覆盖保存设置下，裁剪前会确认。

## 另存为、转换、压缩体积、超分辨率放大

图像名称右侧的“⋯”和图像右键菜单中有常用操作。

- 覆盖保存：以当前保存方式保存（Ctrl+S）。保存到其他文件夹时显示为“保存”。
- 另存为：选择名称和格式，保存为新文件。
- 删除元数据并保存：删除元数据并以当前保存方式保存。
- 查看元数据内容：按类型显示图像包含的信息。
- 其他 → 超分辨率放大：将当前图像放大 1.5–4 倍。隐藏的部分不会被恢复。
- 恢复覆盖前的原图：恢复为本次启动中首次覆盖前的状态。

转换格式和压缩体积在右键菜单中（整个列表请用列表的“⋯”）。原图保持不变，导出到新文件夹。导出前会显示结果，例如“原图 3.2 MB → 压缩后 740 KB（减少 77%）”。在压缩体积中选择“覆盖原图”时，仅将格式不变的图像替换为压缩后的文件（与覆盖保存相同，替换前的原图会保留到应用退出）。

选择 2 张以上时，右键菜单中可使用“并排比较多张”（最多 6 张）和“创建拼贴”。拼贴可网格排列或自由排列，双击图像可就地裁剪。

## 复制与粘贴

Ctrl+C 复制编辑结果，Ctrl+V 在新标签页中打开剪贴板图像。两者都不包含元数据。
粘贴的图像会保存在与设置相同位置的 `clipboard-images` 中，以便恢复标签页。不再需要时，可在退出应用后删除。

## 交给 NovelAI 或其他应用

使用图像名称右侧的“分享”。交付的图像都不包含元数据。

- 用 NovelAI 图生图：复制图像并在浏览器中打开 NovelAI。粘贴或拖入后，选择“Image2Image”。
- 复制图像、拖动交付：可交给社交网站或聊天应用的投稿栏。

## 设置

点击右上角的齿轮打开设置界面。左下角的“恢复初始设置”可将所有设置恢复为初始状态。JPEG 质量在“保存”中，按键分配在“快捷键”中，导航器、全屏显示（F11）和显示语言在“显示、导入”中。
