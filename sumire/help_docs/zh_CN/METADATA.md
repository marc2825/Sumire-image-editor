# 元数据的删除、备份与恢复

## 查看

点击图像上方的“元数据：有 / 无”（或“⋯ → 查看元数据内容”），会按类型列出图像包含的信息。

- 以“项目：内容”的形式显示 EXIF、GPS（位置信息）、生成信息（提示词和设置）、XMP、ICC 配置文件、Stealth PNGInfo 等。
- 无法解读的信息会以“未知”列出，并附上大小。
- “复制文本”可一次复制所显示的内容。

## 删除

**默认情况下，加工后保存也会保留原有元数据。** 删除时请使用以下任一方式。

| 对象 | 操作 |
| --- | --- |
| 当前图像 | 图像上方的“删除元数据” |
| 所选图像 | 列表右键菜单的“删除元数据并保存” |
| 标签页中的所有图像 | 列表上方的“批量删除元数据” |
| 每次保存时 | 开启保存方式中的“保存时删除元数据” |

删除时会去除 EXIF、XMP、PNG 文本、ICC 配置文件等附加信息以及 NovelAI 的 Stealth PNGInfo，并确认保存的图像中没有残留。用另存为、转换格式、压缩体积、创建拼贴生成的文件，无论设置如何都不包含元数据。

即使设置为保留元数据，以其他格式保存时（例如将 PNG 保存为 JPEG）也不会保留。另外，EXIF 缩略图、嵌入 XMP 中的图像等会成为加工前图像副本的内容一律不保留，因此用马赛克隐藏的部分不会以缩略图的形式残留。日期、相机、位置信息、提示词等会保留，分享前请点击“元数据：有”进行确认。

“元数据：无”是对所支持类型的检查结果。以未知方式嵌入的信息或图像中绘制的文字无法检查。
JPEG 每次保存都会重新压缩，像素可能略有变化。

## 为恢复而保留

保存方式中的“保存删除前的元数据以便恢复”开启时（默认），会在改写图像之前，将删除前的元数据保存到管理记录中。无法保存时，不会改写图像。

**压缩并不是加密。管理记录中会原样保留提示词、位置信息、嵌入的缩略图等。**
管理记录保存在应用专用位置，不放在图像文件夹中。如果从 0.4.0 或更早版本开始使用，则位于图像文件夹内的 `.sumire-index.sqlite3`（旧版为 `.sumi-index.sqlite3`）。Windows 会显示以“.”开头的文件，分享整个文件夹时请注意。

这不是图像的备份。覆盖前的原图会保留到应用退出为止（“⋯ → 恢复覆盖前的原图”）。如需在退出后仍保留加工前的图像，请保存到其他文件夹，或保存编辑项目。

## 恢复

1. 显示图像。
2. 在图像名称右侧选择“⋯ → 其他 → 另存带有恢复元数据的副本”。
3. 指定新的文件名。会生成在当前加工结果上附加了删除前元数据的副本。

不会覆盖原图或现有文件。副本中会恢复删除的信息，分享前请确认内容（缩略图等会成为加工前图像副本的内容不会恢复）。
用转换格式、压缩体积、另存为生成的文件也可以恢复。原图为 PNG、JPEG、WebP 时副本保持相同格式，其他格式为 PNG。
**未为恢复而保留的信息无法恢复。**

图像的方向和颜色会按照加工后的图像进行调整。副本与原文件不会完全相同，原图上的签名也不一定有效。
为恢复而保留的数据每张最多 16 MiB，总计最多 128 MiB。

## 保存位置与删除

在“齿轮 → 管理记录”中，可以切换管理记录的保存位置（图像文件夹内 / 应用专用位置）或将其删除。删除后，标签、备注、蒙版和用于恢复的元数据也会被删除。图像和编辑项目会保留。
