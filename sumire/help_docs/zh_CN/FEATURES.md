# Sumīre 功能一览

Sumīre 可以隐藏图像的一部分、查看并删除元数据，还能分拣和导出图像。所有图像处理都在本机进行。

初次使用请先阅读[入门操作](USER_GUIDE.md)。

## 打开与整理

| 想做的事 | 位置 |
| --- | --- |
| 打开图像或文件夹 | 初始界面的按钮、左上角的“文件”，或拖放 |
| 查看 ZIP 中的图像 | “文件 → 打开 ZIP…”或拖放（不解压，只读；用“从 ZIP 导出…”取出所选图像） |
| 同时进行多项工作 | 工作标签页。下次启动时恢复。双击标签页可更改名称 |
| 打开或新建内部文件夹 | 列表上方的文件夹栏 |
| 将图像移到其他文件夹 | 拖到文件夹栏中的文件夹上，或右键菜单的“移动到文件夹” |
| 剪切、复制、粘贴图像文件 | 在列表中按 Ctrl+X、Ctrl+C、Ctrl+V，或右键菜单（也可与资源管理器互通） |
| 搜索与排序 | 搜索框（文件名、备注和标记）、筛选按钮（排序、标签、标记、列表 / 网格和缩略图大小）、在列表中拖动、在图像上方的“4 / 111”中输入编号跳转 |
| 重命名 | 双击图像名称或按 F2。编号可用列表下方的“导出和批量处理 → 按顺序重新编号”或右键菜单（统一位数：00, 01…） |
| 添加备注 | 列表右键菜单的“备注” |
| 从列表中移除 | 右键菜单的“从列表中移除”（不会删除文件，Ctrl+R 或文件夹栏的 ⟳ 可恢复） |
| 删除图像 | 右键菜单的“删除图像…”（确认后移到回收站） |
| 删除重复 | 列表下方的“导出和批量处理 → 删除重复”。保留一张，其余移到回收站 |
| 比较 | 选择 2–6 张，右键菜单的“并排比较多张” |

## 隐藏与调整

| 想做的事 | 位置 |
| --- | --- |
| 隐藏一部分 | 右侧面板的马赛克、模糊、填充。范围可用画笔、矩形、椭圆、多边形、套索 |
| 让马赛克适应图像大小 | 马赛克强度下方的“长边的 1/100”。将每格设为长边的 1/100（向上取整），开启期间每切换一张图像都会重新设置 |
| 在其他图像的相同位置隐藏 | “⋯”或右键菜单的“将加工范围复制到其他图像…”。对所选图像或列表中其他图像的相同位置进行加工并保存 |
| 添加文字 | 在右侧面板选择“文本”（T）后点击图像。可选择字体、大小、颜色和粗体。添加后也可用框移动、旋转、缩放，双击重写 |
| 撤销加工 | 撤销 / 重做、橡皮擦、“重置加工、蒙版” |
| 查看加工位置 | 图像下方的“蒙版”。也可保存为黑白 PNG（“⋯ → 其他”） |
| 与原图比较 | 按住图像下方的“比较”，或按住 Tab |
| 取色、画直线 | Alt+单击为吸管，Shift+单击画直线 |
| 裁剪、放大缩小 | 右侧面板“调整图像”中的“裁剪和更改尺寸…”。拖动四角或边缘确定范围 |
| 旋转、翻转 | 右侧面板的“调整图像” |
| 调整色调 | “调整图像”中的“调整色调…” |
| 更改显示倍率 | 在图像下方的倍率中输入数值、适合窗口按钮（F）、“原尺寸”、Ctrl+滚轮 |
| 放大图像 | “⋯ → 其他”或图像右键菜单的“其他 → 超分辨率放大”（1.5–4 倍） |
| 调用常用设置 | 右侧面板的编辑预设 |

## 分拣

| 想做的事 | 位置 |
| --- | --- |
| 设置标签 | 图像下方的“采用”“待定”“不采用”，或 1、2、3 键。会同时应用到多选的图像 |
| 添加标记 | 右键菜单的“标记…”（多选时一起） |
| 用按钮添加常用标记 | 标签右侧的自定义标记按钮（初始为“需修正”，4–9 键）。用其右侧的标记图标添加、重命名、删除和排序 |
| 按标签分开 | 列表下方的“导出和批量处理 → 按标签导出…”（移入以标签命名的文件夹；也可复制导出、重新编号） |
| 设置标签后立即分拣 | 右键的“标签 → 自动分入标签文件夹”（在有采用、待定、不采用文件夹的位置） |
| 汇总标签文件夹 | 列表下方的“导出和批量处理 → 汇总标签文件夹…” |
| 清除所有标签 | 列表下方的“导出和批量处理 → 重置全部分拣…” |
| 将列表恢复为初始状态 | 列表下方的“导出和批量处理 → 将列表恢复为初始状态”（本次启动中的覆盖、标签、备注、标记、排序、筛选） |
| 撤销整理 | 列表上方的“撤销整理”（Ctrl+Alt+Z）。可撤销标签、标记、排序、名称、备注和移动 |

## 保存与导出

| 想做的事 | 位置 |
| --- | --- |
| 更改保存方式 | 右上角的“覆盖 · 自动保存 ▾” |
| 查看元数据 | 图像上方的“元数据：有 / 无” |
| 删除元数据 | 图像上方的“删除元数据”、列表下方的“导出和批量处理 → 批量删除所有图像的元数据…”。也可设置为每次保存时删除 |
| 恢复删除的元数据 | “⋯ → 其他 → 另存带有恢复元数据的副本” |
| 撤销覆盖 | 右侧面板最下方的“恢复覆盖前”，或“⋯ → 恢复覆盖前的原图”（在应用退出前） |
| 另存为 | “⋯”或图像右键菜单的“另存为” |
| 转换格式 | 右键菜单的“转换格式”（整个列表请用列表下方的“导出和批量处理”） |
| 减小文件体积 | 右键菜单的“压缩体积”。导出前会显示能减少多少。格式不变的图像也可覆盖原图 |
| 按文件大小上限导出 | “转换格式”“压缩体积”中的“文件大小上限”。先降低画质，仍然过大时再缩小图像 |
| 添加水印、签名后导出 | “转换格式”“压缩体积”中的“添加水印、签名”。将文字或签名图像放在角落、中央或整体重复（原图不受影响） |
| 合成为一张 | 选择图像后右键菜单的“创建拼贴”（1 张起）。可网格排列或自由排列，每张都可裁剪 |
| 复制编辑结果、打开粘贴的图像 | Ctrl+C 复制编辑结果，Ctrl+V 在新标签页中打开剪贴板图像 |
| 之后继续加工 | “文件 → 保存包含原图的编辑项目” |
| 交给 NovelAI 或其他应用 | 图像上方的分享按钮（用 NovelAI 图生图、复制图像、拖动交付） |

## 设置

点击右上角的齿轮，可更改保存、管理记录、快捷键、显示、导入、NovelAI 联动、Windows 联动。JPEG 质量（1–100，默认 95）、显示语言和 Windows 右键菜单的注册也在这里。

## 注意事项

- 覆盖保存的原图在应用退出后无法恢复。如需保留原图，请保存到其他文件夹。
- 默认情况下，保存时会保留元数据。如需删除，请使用“删除元数据”，或开启“保存时删除元数据”。
- 马赛克和模糊无法完全隐藏。需要确实隐藏的部分，请使用不透明度 100% 的填充。
- 为恢复而保留的元数据没有加密。详见[元数据与恢复](METADATA.md)。

## 支持的图像

- 可打开静态的 PNG、JPEG、WebP、AVIF、BMP、TIFF、GIF。不支持 HEIC。
- 只有 PNG、JPEG、WebP 可以覆盖保存。其他格式请保存到其他文件夹。
- 不支持动画、图层以及退出后保留编辑历史。
- 图像中绘制的文字或以未知方式嵌入的信息无法删除。
