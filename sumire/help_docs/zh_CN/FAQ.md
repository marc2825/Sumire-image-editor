# 常见问题

## 启动时打开了上次的标签页

会从上次的标签页和工作位置继续。如果在退出前关闭所有标签页，下次会从初始界面开始。撤销、重做的历史不会保留。

## “从列表中移除”会删除文件吗？

不会。只是从该标签页的列表中移除。可通过“文件 → 重新加载列表”（Ctrl+R）恢复。

## 想清除所有加工

使用右侧面板的“重置加工、蒙版”。可用 Ctrl+Z 撤销。打开前就已存在于图像中的加工无法清除。

## 图像没有出现在列表中

请确认是否仍有搜索或筛选条件。可用搜索框右侧的按钮清除。
列表只显示当前文件夹中的图像。内部文件夹中的图像，需要从列表上方的栏位打开该文件夹后才会显示。

## 想更改保存位置

可通过右上角的“覆盖 · 自动保存 ▾”更改。关闭覆盖后，会保留原图并保存到其他文件夹。

## 不小心覆盖了

在退出应用之前可以恢复。

- 用 Ctrl+Z 撤销加工。自动保存开启时，会以撤销后的状态重新保存。但这不是原文件本身（JPEG 会重新压缩）。
- 如需恢复原文件本身，请使用“⋯ → 恢复覆盖前的原图”。需要开启保存方式中的“临时保留覆盖前的原图”（默认开启）。

退出后两者都无法使用。

## 保存后元数据仍然存在

默认情况下，加工后保存也会保留原有元数据。如需删除，请使用图像上方的“删除元数据”，或开启“保存时删除元数据”。点击图像上方的“元数据：有”即可查看残留的内容。

## 只想删除元数据

当前图像用图像上方的“删除元数据”，标签页中的所有图像用列表上方的“批量删除元数据”，所选图像用右键菜单的“删除元数据并保存”。无需涂抹。

## 想减小体积或转换格式

使用右键菜单的“压缩体积”或“转换格式”（整个列表请用列表的“⋯”）。原图保持不变，导出到新文件夹。
平时保存使用的 JPEG 质量可在“齿轮 → 保存”中更改（1–100，默认 95）。

## 无法打开 HEIC

由于许可原因，未附带打开 HEIC 所需的组件。iPhone 等的照片请先转换为 JPEG 再打开。

## 想恢复用“删除重复”删掉的图像

可以从回收站恢复。在无法使用回收站的位置（部分网络驱动器等），图像不会被移动，会保留在原处。

## 无法恢复删除的元数据

只有为恢复而保留了元数据的图像才能恢复。如果关闭了“保存删除前的元数据以便恢复”，或删除了管理记录，则无法恢复。详见[元数据与恢复](METADATA.md)。

## 橡皮擦无法恢复原样

橡皮擦是恢复为应用所记住的加工前图像的功能。覆盖保存并退出后的图像已没有加工前的状态，因此无法恢复。
如需之后修改，请保存到其他文件夹，或保存编辑项目。

## 保存或重命名失败

请检查是否有同名文件、无法使用的字符、写入权限、可用空间，以及是否在其他应用中打开。即使失败，加工也会保留。

## 右键菜单中没有“用 Sumīre 打开”

请在“齿轮 → Windows 联动”中注册。在 Windows 11 中位于“显示更多选项”内。移动 exe 后请重新注册。

## 没有自动导入 NovelAI

应用只负责准备图像和打开浏览器。导入、选择 Image2Image 和生成请在浏览器中操作。

## 想报告问题

在“齿轮 → 信息 → 上次错误的详细信息”中可以复制版本和错误内容。请附上重现步骤，发送到获取 Sumīre 时的联系渠道。请不要附加私人图像或管理记录。
