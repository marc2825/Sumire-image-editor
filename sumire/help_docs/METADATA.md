# メタデータの削除・退避・復元

## 確認する

画像の上の「メタデータ：有り／無し」を押すと（または「⋯ → メタデータの内容を確認」）、含まれる情報を種類ごとに一覧で表示します。

- EXIF・GPS（位置情報）・生成情報（プロンプトや設定）・XMP・ICCプロファイル・Stealth PNGInfoなどを、「項目：内容」の形で表示します。
- 先頭の「日時・場所」に、撮影日時・作成日時・更新日時・緯度経度・高度・カメラを、見つかった情報（EXIF・XMP・PNG・C2PA）からまとめて表示します。どこから読んだかは、値の後ろに書きます。見つからなければ、この欄は出ません。
- ChatGPTなどの画像生成AIが付けるC2PA（コンテンツ認証情報）も読み、作成の方法（AIで生成など）・署名者・作成したツール・使われたAIを表示します。XMPに書かれたAI生成の表示（IPTC）も表示します。署名が正しいかは確かめていません。
- 意味の分からない情報は「不明」として、大きさとともに載せます。
- 画素そのものに埋め込まれる電子透かし（SynthIDなど）はメタデータではないため、表示も削除もできません。
- 「テキストをコピー」で、表示した内容をまとめてコピーできます。

## 削除

**初期設定では、加工して保存しても元のメタデータは残ります。** 削除するには、次のどれかを使います。

| 対象 | 操作 |
| --- | --- |
| 表示中の画像 | 画像の上の「メタデータを削除」 |
| 選んだ画像 | 一覧の右クリックの「メタデータを削除して保存」 |
| タブ内の全画像 | 一覧の上の「メタデータ一括削除」 |
| 保存のたびに | 保存方法の「保存するときにメタデータを削除」をオン |

削除では、EXIF・XMP・PNGのテキスト・ICCプロファイル・C2PAなどの付加情報と、NovelAIのStealth PNGInfoを取り除き、保存した画像に残っていないことを確かめます。別名保存・形式変換・容量削減・コラージュで作るファイルには、設定にかかわらずメタデータは入りません。

メタデータを残す設定でも、形式を変えて保存する場合（PNGをJPEGで保存するなど）は残りません。また、EXIFのサムネイルやXMPに埋め込まれた画像など、加工前の画像の写しになるものは残しません。モザイクで隠した部分が縮小画像として残ることはありません。C2PA（コンテンツ認証情報）は残しますが、縮小画像を含むものは残さず、編集した後は署名が合わなくなります（検証すると「変更あり」と表示されます）。日時・カメラ・位置情報・プロンプトなどは残るので、共有する前に「メタデータ：有り」を押して確かめてください。

「メタデータ：無し」は、対応している種類を調べた結果です。未知の方法で埋め込まれた情報や、画像に描かれた文字は調べられません。
JPEGは保存のたびに圧縮し直すため、画素がわずかに変わることがあります。

## 復元用に残す

保存方法の「削除前のメタデータを復元用に保存」がオン（初期設定）のとき、画像を書き換える前に、消す前のメタデータを管理記録に保存します。保存できなかった場合は、画像を書き換えません。

**圧縮は暗号化ではありません。管理記録には、プロンプト・位置情報・埋め込みサムネイルなどがそのまま残ります。**
管理記録はアプリ専用の場所に保存し、画像フォルダーには置きません。0.4.0以前から使っている場合は、画像フォルダー内の `.sumire-index.sqlite3`（旧版は `.sumi-index.sqlite3`）にあります。Windowsでは「.」で始まるファイルも表示されるので、フォルダーごと共有するときはご注意ください。

これは画像のバックアップではありません。上書きする前の元画像は、アプリを終了するまで残ります（「⋯ → 上書き前の元画像に戻す」）。終了後も加工前の画像を残すには、別フォルダーに保存するか、編集プロジェクトを保存してください。

## 復元

1. 画像を表示します。
2. 画像名の右の「⋯ → その他 → メタデータを復元して別名保存」を選びます。
3. 新しいファイル名を指定します。今の加工結果に、消す前のメタデータを付けたコピーができます。

元画像や既存のファイルは上書きしません。コピーには消した情報が戻るので、共有する前に内容を確かめてください（サムネイルなど、加工前の画像の写しになるものは戻しません）。
形式変換・容量削減・別名保存で作ったファイルからも復元できます。復元したコピーの形式は、元がPNG・JPEG・WebPならその形式、それ以外はPNGです。
**復元用に残していなかった情報は戻せません。**

画像の向きと色は、加工後の画像に合わせて整えます。元のファイルとまったく同じにはならず、元画像に付いていた署名も有効とは限りません。
復元用に残せるのは1枚あたり16MiB、全体で128MiBまでです。

## 保存先と削除

「歯車 → 管理記録」で、管理記録の保存先（画像フォルダー内／アプリ専用の場所）を切り替えたり、削除したりできます。削除すると、ラベル・メモ・マスク・復元用のメタデータも消えます。画像と編集プロジェクトは残ります。
