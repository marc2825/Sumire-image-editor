# Sumīreの機能一覧

画像の一部を隠し、メタデータを確認・削除し、仕分けや書き出しをするアプリです。画像の処理はすべてPC内で行います。

初めての方は[はじめての操作](USER_GUIDE.md)をご覧ください。

## 開く・整理する

| やりたいこと | 場所 |
| --- | --- |
| 画像やフォルダーを開く | 初期画面のボタン、左上の「ファイル」、ドラッグ＆ドロップ |
| ZIPの中の画像を見る | 「ファイル → ZIPを開く…」かドラッグ＆ドロップ（展開せず、読み取り専用。「ZIPから書き出す…」で選んだ画像を取り出せます） |
| 複数の作業を並行する | 作業タブ。次回の起動時に復元します。タブ名はダブルクリックで変更 |
| 中のフォルダーを開く・作る | 一覧の上のフォルダーの欄 |
| 画像を別のフォルダーへ移す | 欄のフォルダーへドラッグ、または右クリックの「フォルダーへ移動」 |
| 画像ファイルを切り取る・コピー・貼り付ける | 一覧で Ctrl+X・Ctrl+C・Ctrl+V、または右クリック（エクスプローラーとも行き来できます） |
| 探す・並べ替える | 検索欄（ファイル名・メモ・タグ）、絞り込みボタン（並び順・ラベル・タグ・一覧／グリッドとサムネイルの大きさ）、一覧でのドラッグ、画像の上の「4 / 111」に番号を入力して移動 |
| 名前を変える | 画像名のダブルクリック、F2。連番は一覧の下の「書き出しと一括処理 → 順に連番へ改名」か右クリック（桁をそろえて00, 01…） |
| メモを付ける | 一覧の右クリックの「メモ」 |
| 一覧から外す | 右クリックの「一覧から外す」（ファイルは消えません。Ctrl+Rかフォルダーの欄の ⟳ で戻ります） |
| 画像を削除する | 右クリックの「画像を削除…」（確認のあと、ごみ箱へ移します） |
| 重複を削除する | 一覧の下の「書き出しと一括処理 → 重複を削除」。残す1枚以外をごみ箱へ移します |
| 見比べる | 2〜6枚を選んで右クリックの「複数枚を並べて比較」 |

## 隠す・整える

| やりたいこと | 場所 |
| --- | --- |
| 一部を隠す | 右パネルのモザイク・ぼかし・塗りつぶし。範囲はブラシ・長方形・楕円・多角形・投げ縄 |
| 文字を入れる | 右パネルの「テキスト」（T）を選んで画像をクリック。フォント・大きさ・色・太字を選べます。入れた後も、枠で移動・回転・拡大縮小、ダブルクリックで書き直し |
| 加工を戻す | 元に戻す／やり直す、消しゴム、「加工・マスクを初期化」 |
| 加工した場所を見る | 画像の下の「マスク」。白黒のPNGでも保存できます（「⋯ → その他」） |
| 元画像と見比べる | 画像の下の「比較」かTabを押している間 |
| 色を拾う・直線を引く | Alt＋クリックでスポイト、Shift＋クリックで直線 |
| 切り抜く・拡大縮小する | 右パネルの「画像の調整」の「切り抜き・寸法の変更…」。四隅や辺をドラッグして範囲を決めます |
| 回転・反転 | 右パネルの「画像の調整」 |
| 色調を変える | 「画像の調整」の「色調の調整…」 |
| 表示倍率を変える | 画像の下の倍率に数値を入力、画面に合わせるボタン（F）、「原寸」、Ctrl＋ホイール |
| 大きくする | 「⋯ → その他」か画像の右クリックの「その他 → 超解像を適用」（1.5〜4倍） |
| よく使う設定を呼び出す | 右パネルの編集プリセット |

## 仕分ける

| やりたいこと | 場所 |
| --- | --- |
| ラベルを付ける | 画像の下の「採用」「保留」「不採用」、または1・2・3キー。複数選択にもまとめて付きます |
| タグを付ける | 右クリックの「タグ…」（複数選択でまとめて） |
| よく使うタグをボタンで付ける | ラベルの右のオリジナルタグのボタン（初期値は「要修正」。4〜9キー）。その右のタグのアイコンで追加・名前の変更・削除・並べ替え |
| ラベルごとに分ける | 一覧の下の「書き出しと一括処理 → ラベルごとに書き出す…」（ラベル名のフォルダーへ移動。コピーして書き出すことも、連番も可） |
| ラベルを付けたらすぐ振り分ける | 右クリックの「ラベル → ラベルのフォルダーへ自動で振り分ける」（採用・保留・不採用のフォルダーがある場所で） |
| ラベルのフォルダーをまとめる | 一覧の下の「書き出しと一括処理 → ラベルのフォルダーをまとめる…」 |
| ラベルを全部外す | 一覧の下の「書き出しと一括処理 → 仕分けをすべてリセット…」 |
| 一覧を最初の状態に戻す | 一覧の下の「書き出しと一括処理 → 一覧を初期状態に戻す」（この起動中の上書き・ラベル・メモ・タグ・並び順・絞り込み） |
| 整理を戻す | 一覧の上の「整理を戻す」（Ctrl+Alt+Z）。ラベル・タグ・並び順・名前・メモ・移動を戻します |

## 保存・書き出す

| やりたいこと | 場所 |
| --- | --- |
| 保存方法を変える | 右上の「上書き · 自動保存 ▾」 |
| メタデータを見る | 画像の上の「メタデータ：有り／無し」 |
| メタデータを消す | 画像の上の「メタデータを削除」、一覧の下の「書き出しと一括処理 → 全画像のメタデータを一括削除…」。保存のたびに消す設定もあります |
| 消したメタデータを戻す | 「⋯ → その他 → メタデータを復元して別名保存」 |
| 上書きを取り消す | 右パネルのいちばん下の「上書き前に戻す」、または「⋯ → 上書き前の元画像に戻す」（アプリを終了するまで） |
| 別名で保存する | 「⋯」か画像の右クリックの「別名で保存」 |
| 形式を変える | 右クリックの「形式を変換」（一覧全体は一覧の下の「書き出しと一括処理」） |
| 容量を減らす | 右クリックの「容量削減」。どれだけ減るかを書き出す前に表示します。形式が変わらない画像は、元画像に上書きすることもできます |
| 1枚にまとめる | 画像を選んで右クリックの「コラージュを作成」（1枚から）。格子か自由な配置で、画像ごとに切り抜けます |
| 編集結果をコピーする・画像を貼り付けて開く | Ctrl+Cで編集結果をコピー、Ctrl+Vでクリップボードの画像を新しいタブに開く |
| あとで加工を再開する | 「ファイル → 元画像を含む編集プロジェクトを保存」 |
| NovelAI・ほかのアプリへ渡す | 画像の上の共有ボタン（NovelAIでi2i・画像をコピー・ドラッグして渡す） |

## 設定

右上の歯車で、保存・管理記録・ショートカット・表示・NovelAI連携・Windows連携を変更できます。JPEGの品質（1〜100、初期値95）、表示言語（日本語・英語・簡体字中国語）、Windowsの右クリックへの登録もここにあります。

## 注意

- 上書きする前の元画像は、アプリを終了すると戻せません。元画像を残すときは「別フォルダーに保存」にしてください。
- 初期設定では、保存してもメタデータは残ります。消すときは「メタデータを削除」を使うか、保存方法で「保存するときにメタデータを削除」をオンにしてください。
- モザイクやぼかしでは完全には隠せません。確実に隠す部分は、不透明度100%で塗りつぶしてください。
- 復元用に残したメタデータは暗号化していません。詳しくは[メタデータ・復元](METADATA.md)をご覧ください。

## 扱える画像

- 開けるのは静止画のPNG・JPEG・WebP・AVIF・BMP・TIFF・GIFです。HEICは開けません。
- 上書き保存できるのはPNG・JPEG・WebPです。ほかの形式は別フォルダーへ保存してください。
- アニメーション、レイヤー、終了後の編集履歴には対応していません。
- 画像に描かれた文字や、未知の方法で埋め込まれた情報は消せません。
