# はじめての操作

基本の流れは「開く → なぞって加工 → 保存 → 次の画像へ」です。

## 1. 開く

初期画面の「フォルダーを開く」「画像を開く」か、ドラッグ＆ドロップで開きます。作業中は左上の「ファイル」（Alt+F）から開けます。

- フォルダーを開くと、直下の画像が一覧に並びます。中のフォルダーは、一覧の上の欄から開けます（[フォルダーを移動する](#フォルダーを移動する)）。
- 画像を選んで開いた場合は、その画像だけが並びます。
- 作業中に開くときは、今のタブに加えるか、新しいタブで開くかを選べます。

次回は、前回のタブと作業位置から始まります。

## 2. 保存方法を決める

初回の起動時に、「元画像に上書き保存する」か「別フォルダーに保存して、元画像を残す」を選びます。選ばずに閉じた場合は、別フォルダーに保存します。

あとから右上の「上書き · 自動保存 ▾」で、次の項目を変えられます。

- 元画像に上書き保存：オフにすると、元画像を残して別フォルダーに保存します。
- 上書き前の元画像を一時的に残す（初期設定でオン）：画像の上の「上書き前に戻す」で、最初に上書きする前の状態に戻せます。残した元画像は、アプリを終了すると削除します。
- 自動保存：オフにすると、Ctrl+Sで手動で保存します。
- 保存するときにメタデータを削除（初期設定でオフ）：オンにすると、保存のたびにメタデータを消します。
- 削除前のメタデータを復元用に保存（初期設定でオン）：消したメタデータを、あとで戻せるように残します。

保存に失敗しても編集は残ります。表示された原因を確かめて、もう一度保存してください。

## 3. 隠す

右パネルでモザイク・ぼかし・塗りつぶしを選び、隠したい部分をなぞります。範囲はブラシのほか、長方形・楕円・多角形・投げ縄でも指定できます。

- Ctrl+Z／Ctrl+Y：元に戻す／やり直す
- 消しゴム（E）：なぞった部分を元画像に戻します。もう一度押すと元のツールに戻ります。
- 比較：画像の下の「比較」かTabを押している間、元画像を表示します。
- マスク：加工した範囲に色を重ねて表示します（この色は保存されません）。
- 加工・マスクを初期化：すべての加工を消します。Ctrl+Zで取り消せます。

文字を入れるときは、「テキスト」（T）を選んで画像をクリックします。開いた画面で文字・フォント・大きさ・色・太字を選ぶと、画像の上で確かめられます。クリックした位置が文字の左上になり、入れた文字は「元に戻す」や消しゴムで消せます。

## 4. 次の画像へ

- ←→キーで前後の画像へ移ります。加工していない画像は、移るだけでは保存しません。
- Enterで、加工していない画像も保存して次へ進みます。
- 自動保存がオフのときは、移る前に保存するかを尋ねます。

## 5. メタデータを確かめる・消す

画像の上の「メタデータ：有り／無し」を押すと、含まれる情報を種類ごとに表示します。

初期設定では、加工して保存してもメタデータは残ります。消すときは次を使います。

- 表示中の画像：画像の上の「メタデータを削除」
- タブ内の全画像：一覧の上の「メタデータ一括削除」（実行前に枚数と保存方法を確認します）
- 選んだ画像：一覧の右クリックの「メタデータを削除して保存」
- 保存のたびに：保存方法の「保存するときにメタデータを削除」をオン

詳しくは[メタデータ・復元](METADATA.md)をご覧ください。

## 6. 仕分ける

### ラベルとタグ

- 右下の「採用」「保留」「不採用」（1・2・3キー）でラベルを付けます。外すときはAlt+0です。
- 「ラベルを付けたら次へ」（初期設定でオン）では、付けると次の画像へ進みます。
- Ctrl・Shiftで複数を選べば、まとめて付けられます。
- 右クリックの「タグ…」で、ラベルとは別に自由なタグも付けられます。
- よく使うタグは、右下の「オリジナルタグ」のボタンで付け外しできます（初期値は「要修正」。上から順に4〜9キー）。「編集」で追加・名前の変更・削除・並べ替えができます。

ラベルを付けても画像は消えません。

### ラベルのフォルダーへ分ける

- ラベルごとに書き出す（一覧の上）：選んだラベルの画像を、ラベル名のフォルダーへ00, 01…と連番で移します。「元画像を移動する」をオフにすると、元画像は残して編集後の画像をメタデータなしで書き出します。
- 自動で振り分ける：右クリックの「ラベル」か、設定 → 表示・取り込み → 仕分け でオンにします。採用・保留・不採用のフォルダーがある場所で、ラベルを付けた画像をすぐそこへ移します（詳しい決まりは、項目にマウスを重ねると出ます）。

### 一覧の整理

- 仕分けをリセット（一覧の上）：ラベルを全部外します。
- 一覧の上の矢印（Ctrl+Alt+Z）：ラベル・タグ・並び順・名前・メモ・移動を戻します。
- 並べ替え：一覧の画像をドラッグします。並び順は検索欄の右のボタンで変えられます。
- 名前の変更：画像名のダブルクリックかF2（Enterで確定、Escで取り消し）
- 連番：一覧の「⋯ → 順に連番へ改名」か右クリック。並んでいる順に00, 01…と振ります。
- 重複を削除：一覧の「⋯ → 重複を削除」。内容が同じ画像を1枚残し、残りをごみ箱へ移します。
- 一覧から外す：右クリック。ファイルは消えず、Ctrl+R（フォルダーの欄の ⟳）で戻ります。
- 画像を削除：右クリックの「画像を削除…」。ごみ箱へ移します（ごみ箱から戻せます）。
- 探す：検索欄にファイル名・メモ・タグの一部を入れます。画像の上の「4 / 111」の番号を書き換えて Enter で、その画像へ移れます。

## フォルダーを移動する

フォルダーを開いたタブでは、一覧の上にフォルダーの欄が出ます。

- フォルダー名をクリックすると、その中へ移ります。「..（上のフォルダー）」か左の矢印で戻ります（タブで開いたフォルダーより上には行けません）。
- 欄の右のボタンで、新しいフォルダーを作れます。
- 画像を欄のフォルダーへドラッグするか、右クリックの「フォルダーへ移動」で移せます。同じ名前があれば `_2` などを付け、上書きしません。ラベル・メモ・タグも一緒に移ります。

## タブ

- Ctrl+T：新しいタブ／Ctrl+W：閉じる／Ctrl+Tab・Ctrl+Shift+Tab：切り替え
- タブ名はダブルクリックで変えられます（空欄でフォルダー名に戻ります）。
- すべて閉じると初期画面に戻ります。

## 加工をあとで再開する

「ファイル → 元画像を含む編集プロジェクトを保存」で、元画像・加工後の画像・マスクをまとめて保存できます（編集履歴は含みません）。

加工前の内容も入っているため、仕上げた画像と一緒に共有しないでください。

## 切り抜き・回転・色調

- 切り抜き：画像の下の「切り抜き」。四隅や辺をドラッグして範囲を決め、内側のドラッグで移動します。数値での指定と、「出力の寸法を指定する」での拡大・縮小もできます。
- 回転・反転：右パネルの「詳細設定・その他」のボタンで、すぐに適用します。
- 色調：同じ場所の「色調の調整」。「詳細調整」でハイライト・シャドウ・白／黒レベル・RGBバランス・シャープネスも変えられます。

どれも「元に戻す」で取り消せます。上書き保存の設定では、切り抜く前に確認します。

## 別名保存・変換・容量削減・超解像

画像名の右の「⋯」と、画像の右クリックに、よく使う操作があります。

- 上書き保存（Ctrl+S）：今の保存方法で保存します（別フォルダーに保存する設定では「保存」）。
- 別名で保存：名前と形式を選んで、新しいファイルに保存します。
- メタデータを削除して保存／メタデータの内容を確認
- その他 → 超解像を適用：1.5〜4倍に拡大します。隠した部分が復元されることはありません。
- 上書き前の元画像に戻す：この起動中に最初に上書きする前の状態に戻します。

形式の変換と容量削減は、右クリック（一覧全体は一覧の「⋯」）から使います。

- 元画像はそのままで、新しいフォルダーに書き出します。
- 容量削減では、「元画像3.2 MB → 圧縮後740 KB（77%削減）」のように結果を先に示します。
- 容量削減の「元画像に上書きする」では、形式が変わらない画像だけを置き換えます（元画像はアプリの終了まで残ります）。

2枚以上を選ぶと、右クリックの「複数枚を並べて比較」（6枚まで）が使えます。「コラージュを作成」は1枚からでき、格子か自由な配置で並べ、画像をダブルクリックすると切り抜けます。

## コピーと貼り付け

- Ctrl+C：編集結果をコピー（メタデータなし）
- Ctrl+V：クリップボードの画像を新しいタブで開く
- 一覧を選んでいるとき：Ctrl+X・Ctrl+C・Ctrl+Vで画像ファイルそのものを切り取り・コピー・貼り付け（エクスプローラーとも行き来できます）

貼り付けた画像は、設定と同じ場所の `clipboard-images` に保管します（アプリの終了後に削除できます）。

## NovelAI・ほかのアプリへ渡す

画像名の右の「共有」から渡します。

- 画像をコピー／ドラッグして渡す：SNSやチャットの投稿欄へ、メタデータを含まない画像を渡せます。
- NovelAIでi2i：画像をコピーし、ブラウザーでNovelAIを開きます。貼り付けかドラッグで取り込み、「Image2Image」を選んでください。

NovelAIへ渡す画像にも、初期設定ではメタデータを含めません。「歯車 → NovelAI連携」で生成情報を付けるようにすると、元画像がPNGのときに付けて渡します。

## 設定

右上の歯車で開きます。

- JPEGの品質：「保存」
- キー操作の変更：「ショートカット」
- ナビゲーター・全画面表示（F11）・表示言語：「表示・取り込み」

左下の「設定を初期状態に戻す」で、すべての設定を最初の状態に戻せます。
