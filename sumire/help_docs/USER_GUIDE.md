# はじめての操作

基本の流れは「開く → なぞって加工 → 保存 → 次の画像へ」です。

## 1. 開く

初期画面の「フォルダーを開く」「画像を開く」か、ドラッグ＆ドロップで開きます。作業中は左上の「ファイル」（Alt+F）から開けます。次回は、前回のタブと作業位置から始まります。

- フォルダーを開くと、その直下の画像が一覧に並びます。中のフォルダーは、一覧の上の欄から開けます（[フォルダーを移動する](#フォルダーを移動する)）。
- 画像を選んで開いた場合は、その画像だけが並びます。
- 作業中に開くときは、今のタブに加えるか、新しいタブで開くかを選べます。

## 2. 保存方法を決める

初回の起動時に、「元画像に上書き保存する」か「別フォルダーに保存して、元画像を残す」を選びます。保存方法は、右上の「上書き · 自動保存 ▾」でいつでも変えられます。選ばずに画面を閉じた場合は、上書き・自動保存になります。初めて上書きするときは確認を表示します。

- 元画像を残す：「元画像に上書き保存」をオフにします。
- 上書きを取り消せるようにする：「上書き前の元画像を一時的に残す」をオンにします（初期状態でオン）。画像の上の「上書き前に戻す」（または「⋯ → 上書き前の元画像に戻す」）で、この起動中に最初に上書きする前の状態に戻せます。**残した元画像は、アプリを終了すると削除します。**
- 手動で保存する：「自動保存」をオフにし、Ctrl+Sで保存します。
- 保存のたびにメタデータを消す：「保存するときにメタデータを削除」をオンにします（初期状態ではオフで、メタデータは残ります）。
- 消したメタデータをあとで戻せるようにする：「削除前のメタデータを復元用に保存」をオンにします（初期状態でオン）。

保存に失敗しても編集は残ります。表示された原因を確かめて、もう一度保存してください。

## 3. 隠す

右パネルでモザイク・ぼかし・塗りつぶしを選び、隠したい部分をなぞります。範囲はブラシのほか、長方形・楕円・多角形・投げ縄でも指定できます。

- 元に戻す：Ctrl+Z。やり直すはCtrl+Y。
- 消しゴム：なぞった部分を元画像に戻します。もう一度押す（E）と元のツールに戻ります。
- 比較：画像の下の「比較」かTabを押している間、元画像を表示します。
- マスク：加工した範囲に色を重ねて表示します。この色は保存されません。
- 加工・マスクを初期化：確認のうえ、すべての加工を消して元画像に戻します。Ctrl+Zで取り消せます。

## 4. 次の画像へ

←→キーで前後の画像へ移ります。何も加工していない画像は、移るだけでは保存しません。
Enterを押すと、加工していない画像も保存して次へ進みます。
自動保存がオフのときは、保存せずに移ろうとすると、保存するかどうかを尋ねます。

## 5. メタデータを確かめる・消す

画像の上の「メタデータ：有り／無し」を押すと、含まれる情報を種類ごとに表示します（「[種類] 項目：内容」の形。意味の分からないものは「不明」）。

初期設定では、加工して保存しても元のメタデータは残ります。消すときは次を使います。

- 表示中の画像：画像の上の「メタデータを削除」
- タブ内の全画像：一覧の上の「メタデータ一括削除」。実行前に、枚数と保存方法を確認します。
- 選んだ画像：一覧の右クリックの「メタデータを削除して保存」

保存のたびに消したい場合は、保存方法の「保存するときにメタデータを削除」をオンにします。[メタデータ・復元](METADATA.md)もご覧ください。

## 6. 仕分ける

右下の「採用」「保留」「不採用」（1・2・3キー）でラベルを付けます。付けると次の画像へ進みます（「ラベルを付けたら次へ」でオン・オフ）。ラベルを付けても画像は消えません。Ctrl・Shiftで複数を選べば、まとめて付けられます。

- ラベルごとに分ける：一覧の上の「ラベルごとに書き出す」。採用・保留・不採用のどれか、またはすべてのラベルを選ぶと、開いているフォルダーにラベル名のフォルダーを作り、00, 01…と連番を振って移します。「元画像を移動する」をオフにすると、元画像はそのままで、編集後の画像をメタデータなしで書き出します。保存先や連番の有無も変えられます。
- ラベルを全部外す：一覧の上の「仕分けをリセット」。
- 直前の整理を戻す：一覧の上の矢印（Ctrl+Alt+Z）。ラベル・並び順・名前・メモ・フォルダーの移動を戻せます。
- 並べ替え：一覧の画像をドラッグします。並び順は検索欄の右のボタンで変えられます。
- 名前の変更：画像名のダブルクリックかF2。Enterで確定、Escで取り消します。
- 連番：一覧の「⋯ → 順に連番へ改名」か右クリック。一覧に並んでいる順に番号を振ります。桁は最大の番号より1桁多くそろえます（3枚なら00〜02）。
- 重複の削除：一覧の「⋯ → 重複を削除」。内容が同じ画像のうち、残す1枚以外をごみ箱へ移します。
- 一覧から外す：右クリックの「一覧から外す」。ファイルは消えず、Ctrl+R（フォルダーの欄の ⟳）で戻ります。
- 探す：検索欄に、ファイル名かメモの一部を入れます。画像の上の「4 / 111」の番号を書き換えて Enter で、その画像へ移れます。

## フォルダーを移動する

フォルダーを開いたタブでは、一覧の上にフォルダーの欄が出ます。

- フォルダー名をクリックすると、そのフォルダーの画像に切り替わります。「..（上のフォルダー）」か左の矢印で戻ります。タブで開いたフォルダーより上には行けません。
- 欄の右のボタンで、新しいフォルダーを作れます。
- 画像を欄のフォルダーへドラッグするか、右クリックの「フォルダーへ移動」で移せます。同じ名前の画像があるときは `_2` などを付け、上書きしません。ラベルやメモも一緒に移ります。

## タブ

Ctrl+Tで新しいタブ、Ctrl+Wで閉じ、Ctrl+Tab／Ctrl+Shift+Tabで切り替えます。すべて閉じると初期画面に戻ります。
タブ名はダブルクリックで変えられます。空欄にするとフォルダー名に戻ります。

## 加工をあとで再開する

「ファイル → 元画像を含む編集プロジェクトを保存」で、元画像・加工後の画像・マスクをまとめて保存できます。
**加工前の内容も入っているため、仕上げた画像と一緒に共有しないでください。** 編集履歴は保存しません。

## 切り抜き・回転・色調

- 切り抜き：画像の下の「切り抜き」。最初は画像全体が枠で囲まれています。四隅や辺をドラッグして範囲を調整し、枠の内側をドラッグすると移動します。数値でも指定できます。「出力の寸法を指定する」で拡大・縮小もできます。
- 回転・反転：右パネルの「詳細設定・その他」のボタンで、すぐに適用します。
- 色調：同じ場所の「色調の調整」。明るさ・コントラスト・彩度・色相・露出・色温度・ガンマを変えられ、「詳細調整」を開くとハイライト・シャドウ・白／黒レベル・RGBバランス・シャープネスも使えます。画面内の「元に戻す」「やり直す」（Ctrl+Z／Ctrl+Y）で一手ずつ戻せます。

どれも「元に戻す」で取り消せます。上書き保存の設定では、切り抜く前に確認します。

## 別名保存・変換・容量削減・超解像

画像名の右の「⋯」と画像の右クリックに、よく使う操作があります。

- 上書き保存：今の保存方法で保存します（Ctrl+S）。別フォルダーに保存する設定では「保存」と表示します。
- 別名で保存：名前と形式を選んで、新しいファイルに保存します。
- メタデータを削除して保存：メタデータを消して、今の保存方法で保存します。
- メタデータの内容を確認：含まれる情報を種類ごとに表示します。
- その他 → 超解像を適用：表示中の画像を1.5〜4倍に拡大します。隠した部分が復元されることはありません。
- 上書き前の元画像に戻す：この起動中に最初に上書きする前の状態に戻します。

形式の変換と容量削減は、右クリック（一覧全体は一覧の「⋯」）から行います。元画像はそのままで、新しいフォルダーに書き出します。容量削減では、書き出す前に「元画像3.2 MB → 圧縮後740 KB（77%削減）」のように結果を示します。容量削減の「元画像に上書きする」を選ぶと、形式が変わらない画像だけを、小さくした画像で置き換えます（置き換える前の元画像は、上書き保存と同じくアプリの終了まで残ります）。

2枚以上を選ぶと、右クリックから「複数枚を並べて比較」（6枚まで）と「コラージュを作成」が使えます。コラージュでは、格子に並べるか自由に配置でき、画像をダブルクリックするとその場で切り抜けます。

## コピーと貼り付け

Ctrl+Cで編集結果をコピーし、Ctrl+Vでクリップボードの画像を新しいタブに開きます。どちらもメタデータは含みません。
貼り付けた画像は、タブを復元するために設定と同じ場所の `clipboard-images` に保管します。不要になったら、アプリを終了してから削除できます。

## NovelAI・ほかのアプリへ渡す

画像名の右の「共有」から渡します。どれもメタデータを含みません。

- NovelAIでi2i：画像をコピーし、ブラウザーでNovelAIを開きます。貼り付けかドラッグで取り込み、「Image2Image」を選んでください。
- 画像をコピー・ドラッグして渡す：SNSやチャットの投稿欄へ渡せます。

## 設定

右上の歯車で設定画面を開きます。左下の「設定を初期状態に戻す」で、すべての設定を最初の状態に戻せます。JPEGの品質は「保存」、キー操作の変更は「ショートカット」、ナビゲーター・全画面表示（F11）・表示言語は「表示・取り込み」にあります。
