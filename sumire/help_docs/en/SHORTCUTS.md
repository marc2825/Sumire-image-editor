# Shortcuts

These are the default keys. Change them in “Settings (gear) → Shortcuts” at the top right (up to two keys per command; a key cannot be used for two commands). Keys that act on the image work when the image area is selected. While you type text, typing takes priority.

| Command | Key |
| --- | --- |
| Open folder | Ctrl+O |
| “File” menu | Alt+F |
| Reload the list (brings back removed images) | Ctrl+R |
| Save | Ctrl+S |
| Previous / next image | ← / → |
| Save and next (saves even if unedited) | Enter |
| Undo / redo | Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) |
| New tab / close tab | Ctrl+T / Ctrl+W |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab |
| Rename | F2, or double-click the image name |
| Search names, notes and tags | Ctrl+F |
| Accept / Hold / Reject | 1 / 2 / 3 |
| Remove label | Alt+0 |
| Add or remove custom tags 1–6 | 4–9 |
| Undo the last organising step | Ctrl+Alt+Z |
| Toggle the eraser | E |
| Toggle the text tool | T |
| Show the mask | M |
| Compare with the original | Tab (while held) |
| Zoom in / out | Wheel / + / −. You can also type a number into the zoom box below the image and press Enter |
| Move the view | Space + drag / drag with the middle button |
| Fit / actual size | F / Ctrl+1 |
| Smaller / larger brush | [ / ] |
| Weaker / stronger | , / . |
| Cancel while tracing | Esc |
| Help | F1 |
| Copy (image files in the list, otherwise the result) | Ctrl+C |
| Cut image files | Ctrl+X |
| Paste (image files into the tab's folder; a picture opens as new) | Ctrl+V |
| Full screen | F11 |
| Show or hide the list | Ctrl+B |
| Show or hide the tools | Ctrl+Shift+B |

## Fixed keys

| Command | Key |
| --- | --- |
| Eyedropper | Alt+click |
| Straight line from the last brush position | Shift+click |
| Add a polygon point / finish | Click / Enter or double-click |
| Remove the last point / cancel | Backspace / Esc |
| Confirm / cancel a name | Enter / Esc |
| Rewrite / remove a text | Double-click its box / Delete |
| Rotate a text in 15° steps | Shift + drag the rotation circle |

“Undo” only undoes edits to the image. Labels, tags, order, names, notes and folder moves are undone with “Undo the last organising step”.
