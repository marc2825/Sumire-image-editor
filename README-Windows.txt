Sumīre 1.1.1 / Windows 11 x64

はじめに
ZIPをすべて展開し、sumire.exe をダブルクリックします。Pythonは要りません。
sumire.exe は同じフォルダーの _internal を使います。フォルダーごと置き、exe だけを移さないでください。
初回は、保存方法を「元画像に上書き」か「別フォルダーに保存（元画像は残る）」から選びます。選ばずに閉じた場合は、上書き・自動保存になります。あとから右上の「上書き · 自動保存 ▾」で変えられます。
画像やフォルダーは、画面へドロップしても開けます。次回は、前回のタブと作業位置から始まります。

基本の操作
隠したい部分をなぞると、自動で保存します。Enterで保存して次の画像へ、←→で前後の画像へ移ります。
左は画像の一覧、中央は画像、右は編集ツールと仕分け（採用・保留・不採用。キーは1・2・3）です。
困ったときは、右上の「？」かF1でヘルプを開いてください（オフラインで読めます）。

主な機能
・作業タブ：Ctrl+Tで新しいタブ、Ctrl+Wで閉じる。タブ名はダブルクリックで変更。
・フォルダー：一覧の上の欄から、中のフォルダーを開いたり作ったりできます。画像をフォルダーへドラッグすると移動します。
・画像の右クリック：別名で保存、形式の変換、容量削減、超解像、比較、コラージュ、連番、一覧から外す。
・切り抜き・比較・マスクは画像の下、回転・反転と色調は右パネルの「詳細設定・その他」にあります。
・Ctrl+Cで編集結果をコピー、Ctrl+Vでクリップボードの画像を新しいタブに開きます。

メタデータ
初期設定では、保存してもメタデータは残ります。消すときは、画像の上の「メタデータを削除」か、一覧の上の「メタデータ一括削除」を使います。保存のたびに消す設定もあります。
画像の上の「メタデータ：有り」を押すと、含まれる情報を確認できます。
削除前の情報は、「⋯ → その他 → メタデータを復元して別名保存」で戻せます。この情報は暗号化しておらず、プロンプトや位置情報も読めます。アプリ専用の場所に保存し、画像フォルダーには置きません（0.4.0以前から使っている場合は、画像フォルダー内の .sumire-index.sqlite3）。
「メタデータ：無し」は、対応している種類を調べた結果です。未知の方法で埋め込まれた情報は調べられません。

右クリックからの起動
展開したフォルダーの置き場所を決めてから、右上の歯車 →「Windows連携」→「右クリックに『Sumīreで開く』を追加」を選びます。画像やフォルダーを右クリック →「その他のオプションを確認」→「Sumīreで開く」で起動します。
フォルダーを移動したら登録し直し、削除する前に登録を解除してください。

更新
新しいZIPを別のフォルダーに展開し、古いアプリを終了してから起動します。設定・記録・編集プロジェクトはそのまま使えます。展開したフォルダーを削除しても、画像・設定・記録は残ります。記録の保存先の変更や削除は、歯車の「管理記録」で行います。右クリックに登録している場合は、新しいフォルダーで登録し直してください。

アンインストール
1. 右クリックに登録している場合は、展開したフォルダーの unregister-context-menu.cmd をダブルクリックして解除します（歯車 →「Windows連携」→「右クリックの登録を解除」でも同じです）。
2. 設定と記録も消す場合は、歯車の「管理記録」で記録を削除してから、%LOCALAPPDATA%\Sumīre フォルダーを削除します（0.4.0以前から使っている場合は、画像フォルダー内の .sumire-index.sqlite3 も）。
3. 展開したフォルダーを削除します。画像は消えません。
